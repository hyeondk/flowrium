# Flowrium 0.5.0 검증 기록

검증일 / 2026-11-13

이 문서는 새 탐색 화면과 대화 범위의 검증 결과를 기록합니다. 최종 설치와 공개 배포 결과는 확인한 뒤 갱신합니다. [사용 범위와 남은 차이](REPLACEMENT-STATUS.md)도 함께 확인하세요.

## 새 화면과 동작

- 왼쪽 아이콘 메뉴의 실제 마우스 진입과 이탈 / 키보드 진입과 이탈 / 고정 선택의 새로고침 복원을 검사했습니다. 메뉴를 펼치고 접기 전후 본문 위치와 크기가 유지됐습니다.
- 오른쪽에서 통합 채팅 / 일반 대화 / 프로젝트 대화를 실제 생성하고, 가운데 대시보드가 유지되며 서로 다른 식별자와 저장 범위를 갖는 것을 확인했습니다.
- 실제 모의 실행과 승인 요청을 만들어 작업중 1 / 대기 1 / 결정 1을 각각 다른 대화로 집계하고 상태별 필터와 프로젝트 메뉴의 결정 표시를 검사했습니다. 유휴 대화를 대기로 잘못 표시하지 않습니다.
- 1440 / 1280 / 1024 / 390픽셀에서 문서와 본문 내부의 가로 넘침을 측정했습니다. 같은 대시보드 버튼 그룹의 높이 40픽셀, 로컬 글꼴과 한글 어절 줄바꿈, 모바일 대화함의 하단 시트를 확인했습니다.
- 앱의 공식 글꼴 4종 / 웹의 공식 글꼴 3종은 로컬 파일로 로딩합니다. 외부 글꼴 서비스에 요청하지 않습니다. 원본 출처와 OFL 라이선스를 포함합니다.
- 팝업의 배경 어둡게 / 90%에서 100% 확대 / 들어올 때 감속과 나갈 때 가속 / 닫힘 중 화면 유지 / 빠른 재열기를 검사했습니다. 토스트와 스낵바의 입퇴장 / 하단 시트 / 체크 표시의 중간 프레임 / 일정한 로딩 / 제목 순차 등장 / 동작 줄이기를 확인했습니다.

설정 팝업을 열어도 초점이 원래 버튼에 남고 Tab이 배경으로 이동하는 회귀를 실제로 재현했습니다. 팝업의 실제 마운트 상태를 부모의 초점 처리와 연결하도록 수정했습니다. 동일한 열기 조건에서 최초 초점 / Tab 정순·역순 순환 / Escape 퇴장 완료 / 원래 버튼으로 초점 복구를 재검사해 통과했습니다.

## 대화 범위와 계정 분리

일반 대화와 통합 채팅은 사용자 계정별 앱 데이터에 저장합니다. 같은 계정 재로그인 복원 / 다른 계정의 식별자 접근 거절 / 잠금과 계정 변경 중 도구·첨부 반환 차단 / 설정의 Codex 경로 변경 시 전용 실행 연결 정리를 검사했습니다. 프로젝트의 기존 대화 저장소와 섞이지 않습니다.

실제 번들 Codex를 로컬 모의 Responses 서버에 연결해 제한 권한 프로필 / 이미지와 문서 첨부 / 실제 분기와 되감기 / 통합 현황 도구 왕복을 검사했습니다. 일반 대화에서 실제 프로젝트 파일에 변경을 시도하는 모델 도구 호출은 운영체제의 접근 제한으로 거부되며 원본 파일이 유지됩니다.

통합 채팅의 요청은 결정함에 제안하고, 승인 전에는 프로젝트 실행이 없음을 확인했습니다. 승인 뒤 해당 프로젝트에서 구현 대화를 실행하고 완료 결과를 원래 통합 채팅으로 회신했습니다. 조회는 프로젝트 100개 / 프로젝트별 최근 대화 15개 / 최근 메시지 4개로 제한합니다.

## 실제 ChatGPT 계정

이전 버전에서 합성 완료 업무 두 건으로 AI 주간보고와 산출물 저장을 검사했습니다. 새 일반 대화와 통합 현황 조회는 실제 ChatGPT 모델에서 14초에 통과했습니다. 등록 프로젝트 1개 / 점검한 문구 3개를 정확히 답하고 통합 현황 동적 도구 1회 호출을 확인했습니다. [실제 계정 기록](validation/actual-chatgpt-scopes.md)에 조건과 답변을 남겼습니다. 실제 계정 검사도 합성 자료만 사용하며 모든 외부 서비스와 기능의 실사용 완료를 뜻하지 않습니다.

## 회귀와 배포 상태

로컬 타입 검사 / 프로덕션 빌드 / 단위 검사 153개 / 채팅 첨부·추가 지시·분기·되감기 / 보안·초안·음성·기억 / 프로젝트 업무·활동 목록의 회귀를 확인했습니다. 배포 의존성의 알려진 취약점은 0개입니다.

Mac ARM64 새 설치본의 임시 서명 무결성 / ARM64 아키텍처 / 디스크 이미지 체크섬 / 실행 소스 11개와 화면 JS·CSS·글꼴의 바이트 일치를 확인했습니다. 별도 사용자 데이터로 내장 터미널과 PDF·PPTX / 기본 일정 도우미를 검사했습니다. 실제 업데이트 버튼에서 미공증 새 ZIP의 자동 교체를 거절하고 기존 앱을 유지하며 수동 다운로드를 안내하는 경로를 확인했습니다. 네이티브 교체 도우미의 성공 / 시작 직후 실패와 복원, 터미널 설치기의 백업·변조·경로 검증도 통과했습니다.

Windows 첫 실행에서는 빌드 / 단위 / 설치 파일 생성 / 패키지 내장 터미널을 통과했지만 작은 화면용 대화함이 열린 상태의 메뉴 탐색에서 화면 검사가 멈췄습니다. 데스크톱 기능 검사의 시작 화면을 1440×1000으로 명시하고 오버레이를 닫은 뒤 탐색하도록 보강했습니다. 별도의 390 / 320픽셀 좁은 화면 검사는 유지합니다. 제품 소스는 바꾸지 않았으며 Mac의 같은 업무 검사를 다시 통과했습니다.

Windows x64 새 설치본과 업데이트의 최종 결과 및 공개 소스 커밋은 배포가 완료된 뒤 이 문서에 추가합니다.

실제 Google / 카카오 / 개인 Mac 메일·캘린더 권한 / 개인 마이크와 음성 모델 / 실제 휴대폰 외부 회선과 웹 푸시 / 실제 노래 가사의 정확성은 모의 검사와 구분합니다. 현재 Mac은 Developer ID 서명과 Apple 공증이 없어 다운로드본의 경고 없는 설치와 앱 내부 자동 교체를 보장하지 않습니다. 터미널 설치는 운영체제 보안을 해제하지 않습니다.
