# Flowrium 0.6.0 검증 기록

검증일 / 2026-11-13~2026-11-14

Mac 소스의 타입 검사 / 빌드 / 단위 검사 201개가 통과했습니다. 전체 자료 이관 / 음성 서버 / 자동 포트표 / 보고와 마감 팝업의 실제 Mac 앱 검사도 통과했습니다. Mac 최종 패키지와 Windows 전체 회귀 / 설치 / 업데이트 / 신규 기능 검사가 모두 통과했습니다. 배포 소스는 `51efc2fe89940726ebf8879cf876c969ff916936`입니다. [0.6.0 공개 릴리스](https://github.com/hyeondk/flowrium/releases/tag/v0.6.0)에서 받습니다. [파일별 대조 기록](validation/release-0.6.0.json) / [Windows 검사 요약](validation/windows-0.6.0.json)을 보관했습니다.

## 검증 범위

전체 자료 이관의 사본 / 새 식별자와 경로 / 원문과 첨부 / 설정·기억 / 인증 제외 / 변조·위험 경로 / 충돌 / 실패 되돌림 / 다음 기동 복구를 합성 자료로 검사합니다. 개인 원본에 실제 이관을 적용하지 않습니다.

음성 서버는 실제 로컬 시험 프로세스를 띄워 시작 / 재시작 / 중지 / 외부 서버 보존 / 자식 프로세스 정리 / 잠금·계정·종료 / 실패 로그를 확인합니다. 실제 마이크와 개인 음성 모델의 인식 품질은 별도입니다.

포트표는 실제 로컬 수신 서버를 사용해 배정 / 충돌 / 예약 / 사용자 지정 / 재시작 보존 / 숫자 휠과 초점 / 여러 화면 폭을 확인합니다. 다른 서버를 종료하거나 연결 요청을 보내지 않습니다.

화면은 실제 Electron 창에서 파란색 팔레트 / 로컬 글꼴 / 행 높이 / 자연스러운 줄바꿈 / 왼쪽 메뉴 정렬 / 중앙 팝업 / 키보드 초점 / 스위치 / 체크 선 / 좋아요 탄성 / 알림·시트 / 인증 후 잠금 해제 / 동작 줄이기를 검사합니다. 보고와 마감은 실제 연결 모델 목록을 사용하며 모의 모델로 선택 내용이 업무 실행에 전달되는지 확인합니다.

Mac ARM64와 Windows x64의 설치·업데이트 검사는 배포 산출물 검증 후 기록합니다. [0.5.0 기존 검증](VALIDATION-0.5.0.md)과 혼동하지 않습니다.

## Mac 화면과 회귀

공식 로컬 글꼴 / 밝은·어두운 테마 본문 대비 / 768·390·320픽셀 대시보드와 상세 탭 / 중앙 팝업 / 스위치·좋아요·체크 선 / 인증 후 잠금 해제 / 동작 줄이기를 실제 창에서 검사했습니다. 공통 스타일이 강조 버튼을 덮어쓰던 원인을 수정하고 같은 대비 검사를 통과했습니다. 메뉴가 펼쳐지는 도중 고정 버튼으로 이동하면 접히던 조건은 포인터 종료 지연을 추가한 뒤 같은 클릭 시나리오를 통과했습니다.

프로젝트 포트폴리오 / 목표·산출물 / 업무 연결 / 기억 / 팀 배정·자동 운영·독립 Git 폴더 / 질문과 비밀 입력 / 외부 자료·일정·주소 전달 / 모바일 / 문서 변환 / 공개 페이지를 격리된 프로필에서 회귀 검사했습니다. 채팅·음성·도구 / 구버전 초안의 재검사도 통과했습니다. 초안 이관은 읽은 원문을 보관한 경우에만 삭제하고 삭제 직전 값이 달라졌으면 새 값을 유지합니다. 개인 Google·카카오·메일·캘린더·마이크·음성 모델과 휴대폰 외부 회선은 이번 검사 대상이 아닙니다.

## Mac 최종 설치본

`/Applications/Flowrium.app`에 0.6.0을 설치했으며 이전 설치본은 `/Applications/Flowrium.app.backup-20261113-234550-57199`에 보존했습니다. 사용자 프로젝트와 대화는 설치 경로와 분리되어 있습니다. 최종 DMG / ZIP / 설치 앱의 `app.asar`가 같고 실행 소스·화면 파일 66개가 최종 저장소와 바이트 단위로 일치합니다. 검사·워크플로만 바뀐 최종 커밋과 실제 앱 빌드 커밋은 [Mac 검사 기록](validation/mac-0.6.0.json)에 구분했습니다.

ARM64 / 임시 서명 무결성 / 이미지 체크섬 / 독립 Node·GitHub 실행기 / 새 계정의 미로그인 상태 / 패키지 문서 변환·터미널 / 신규 자료 이관·음성·포트 API / 실제 업데이트 버튼 / 미공증 ZIP 차단·기존 앱 보존 / 교체 도우미 준비·실패 복원 / 터미널 설치기 검사를 통과했습니다.

설정 화면 시험 중 운영체제 키체인 읽기 대기로 멈춘 조건은 실제 스레드 표본으로 확인했습니다. 연결이 꺼진 휴대폰 알림 상태 조회가 안전 저장소를 호출하지 않도록 보완했고, 키체인 호출 0회 / 활성 연결의 암호화·복호화 복원을 단위 검사했습니다. 보완 뒤 최종 패키지의 실제 업데이트 버튼 검사는 별도 보안 우회나 모의 키체인 옵션 없이 통과했습니다. 실제 외부 연결의 모든 키체인 권한을 확인했다는 뜻은 아닙니다. 관련 시험 조건은 [Electron 공식 기록](https://releases.electronjs.org/pr/53790)도 참고할 수 있습니다.

## 모델과 보고 팝업

현재 로그인 연결의 `model/list`를 읽어 GPT-6.1 Sol / Terra, GPT-6 Astra / Sol / Luna 등을 확인했습니다. 모델별 지원 강도는 [실제 반환 목록](validation/model-catalog-0.6.0.json)에 기록했습니다. 목록 조회만 수행했으며 인증 자료를 출력하거나 복사하지 않았습니다. 주간보고 / 업무 마감은 선택 모델과 강도가 실제 `turn/start`에 전달되는 경로를 모의 모델로 검증했습니다.

ChatGPT 화면의 Instant / Pro 명칭을 다른 모델로 임의 대응하지 않습니다. [공식 연결 명세](https://learn.chatgpt.com/docs/app-server)에 따라 계정에서 반환한 모델과 추론 강도를 표시합니다. 실제 계정·정책에 따라 목록은 달라질 수 있습니다. [새 중앙 팝업 화면](weekly-popup.png)은 합성 프로젝트와 검증용 모델의 예시입니다.

첫 Windows 검사에서는 운영체제의 짧은 임시 경로와 실제 경로를 검사 코드가 다르게 비교한 조건을 확인했습니다. 네 전용 검사에서 임시 루트를 실제 경로로 정규화한 뒤 통과했습니다. 팀 실행 검사도 고정 횟수 약 3초 대기 대신 제한 시간 안에 실제 완료 상태를 기다리게 보완했습니다. 제품 경로와 팀 실행 동작은 이 보완으로 바꾸지 않았습니다.

전체 회귀와 최종 설치본 검사는 [실행 43446713139](https://github.com/hyeondk/flowrium/actions/runs/43446713139) / 작업 131957959319 / 같은 소스에서 모두 통과했습니다. Windows 새 프로필의 미로그인 상태 / 문서 변환 / 내장 터미널 / 모든 화면 회귀 / 실제 설치와 이전 앱 백업 / 공개 0.5.0의 실제 업데이트 버튼에서 0.6.0 다운로드·설치·재시작 / 프로젝트·메시지·초안·작업 모드 복원 / 신규 기능 4종과 최종 게이트를 확인했습니다.

Windows 아티팩트는 `14048233996` / `flowrium-win-x64` / 323119656바이트이며 원본 ZIP의 SHA-256은 `695daa5f4e64c819c95f7f0b023eaf62ec715edaa5b672723c7e43155efbf500`입니다. GitHub API의 크기와 검증값을 대조한 뒤 설치 파일 하나만 추출했습니다.

Mac 공개본에는 Apple Developer ID와 공증이 없습니다. 설치한 앱의 실제 Gatekeeper 평가는 종료 코드 3 / 거절이며, 임시 서명 무결성 검사 통과와 구분합니다. 이 맥의 로컬 설치와 격리 실행 검사는 통과했지만 공개 다운로드본의 경고 없는 첫 실행은 보장하지 않습니다. Windows 공개본도 배포용 서명이 없으므로 운영체제의 확인이 표시될 수 있습니다. 터미널 설치기는 운영체제 정책을 해제하지 않습니다.

## 공개 배포와 최종 정리

Mac DMG·ZIP / Windows 설치본 / 소스 묶음 / 두 터미널 설치기 / 소스 검증 도구 / 소스 커밋 / 체크섬의 9개 파일을 공개했습니다. 크기와 SHA-256을 GitHub 파일 정보 및 로컬 파일에 모두 대조했습니다. 공개 태그와 소스 커밋이 일치하고 비로그인 공개 릴리스 / 다운로드 페이지 / 두 운영체제 다운로드 링크가 정상입니다.

Windows 단위 검사는 201개 중 200개 통과 / 실패 0개 / 심볼릭 링크 생성 권한에 의존하는 1개 제외입니다. Mac은 201개 모두 통과했습니다. 태그가 시작한 중복 빌드는 취소했으며 이미 통과한 동일 소스의 산출물을 사용합니다.

최종 설치 앱 / 이전 앱 백업 / 소스 / 배포 파일 / 실행 필수 런타임을 보존합니다. 개인 자료의 실제 이관과 사용하지 않은 외부 서비스의 실계정 검사는 사용자가 필요한 범위에서 확인해야 합니다. 기존 앱과 개인 원본을 자동 삭제하지 않았습니다.

작업용 Electron / Flowrium 프로세스 0개와 시험 음성 서버 종료를 확인했습니다. 이번 작업의 임시 앱·프로필·로그·중간 ZIP·컴파일 캐시 등 51개 항목을 정리했으며 `.flowrium-tmp/runtime`과 최종 배포 파일 / 설치 앱 / 이전 앱 백업 / 소스·사용자 자료는 보존했습니다.
