# Flowrium 화면 구성과 움직임

기준 버전은 261115_02입니다. 대시보드와 우측 대화를 독립적으로 탐색하며 조밀한 제어 요소와 파란색·회색 그라데이션을 사용합니다.

## 대화

- 대화는 우측에 고정하고 왼쪽 대시보드와 자료 화면을 유지합니다. 패널 폭 확대도 본 화면을 숨기지 않습니다. 메뉴에서 겹쳐 보기나 기존 대화의 입력창만 보기를 명시적으로 선택합니다.
- 상태 필터는 상단의 작업중, 대기, 결정 세 가지입니다. 대화 종류와 무관하게 상태와 개수를 확인할 수 있습니다.
- 제목과 행동 버튼을 같은 행에 배치하고, 연결 안내는 필요한 경우 펼쳐 읽습니다.
- 과거 메시지 제어는 본문과 함께 스크롤합니다. 안내가 본문 위를 계속 덮지 않습니다.
- 첨부와 음성, 모드, 모델, 전송을 입력창의 도구 행에 배치합니다. 입력은 내용에 따라 늘어나며 본문을 과하게 가리지 않도록 높이를 제한합니다.
- 긴 코드와 표는 해당 블록에서 가로로 스크롤합니다. 일반 문장은 한글 어절을 유지합니다.
- 상단 알림은 읽음 상태와 원대화 이동을 제공하고 중앙 팝업으로 열립니다. 음악도 본 화면을 바꾸지 않는 팝업입니다. Dots는 별도 로그인 세션의 공식 웹 화면이며 다른 팝업이 열리면 네이티브 뷰를 숨깁니다.
- 작성 지시문은 일반 답변으로 렌더하고 큰 도구 JSON과 작업 상태는 기본 접힌 행으로 표시합니다. 원문은 별도 보기와 복사에서 보존하며 답변 읽기에는 숨은 도구와 서식 지시문을 넣지 않습니다.

## 탐색 메뉴

프로젝트 목록은 배정된 높이 안에서 스크롤합니다. 목록이 보관과 도구 메뉴의 영역을 침범하지 않으며, 접힘과 펼침 때 기존 아이콘의 세로 위치를 유지합니다. 프로젝트 추가 버튼도 같은 가로 위치를 사용합니다. 로고는 접힌 패널의 중앙에 두고, 펼친 상태에서는 메뉴 아이콘 중심선과 맞춥니다.

## 공통 간격과 역할

| 요소 | 기준 |
| --- | --- |
| 카드 내부 | 16px를 기본으로 내용에 필요한 간격 유지 |
| 기능 영역 사이 | 데스크톱 14~18px |
| 행동 버튼 사이 | 8px |
| 일반 제어 요소 | 데스크톱 버튼 30~32px, 입력 34px, 둥근 모서리 |
| 반복되는 메뉴 행 | 도구 30px, 짧은 창 28px, 프로젝트 34px |
| 제목 | 역할에 따라 15px부터 24px, 일정한 줄 높이 |
| 본문 | 13px 또는 14px, 어절 단위 줄바꿈 |
| 주요 실행 | 파란색 면과 흰 글자 |
| 보조 행동 | 투명한 면과 호버 강조 |
| 부가 정보 | 괄호, 짧은 부제 또는 별도 행 |

바탕과 작업 면, 떠 있는 면의 명도와 그림자를 구분합니다. 배경은 연한 파란색과 회색으로 구성하며 글자가 겹쳐 보이지 않도록 펼친 탐색 메뉴는 불투명한 면을 사용합니다. 상단 막대는 44px, 탐색 레일은 72px, 펼친 면은 240px입니다. 프로젝트에 남은 높이를 우선 배정하고 도구는 하단에 모읍니다. 하단에는 남은 사용량과 제작자 © hyeondk를 표시합니다. 터치 환경은 기존 클릭 영역을 유지합니다.

## 움직임

| 대상 | 적용 기준 |
| --- | --- |
| 스낵바 | 아래에서 들어오고 아래로 퇴장 |
| 토스트 | 같은 위치에서 투명도 변화 |
| 팝업 | 중앙 위치 유지, 90%에서 100% 확대, 배경은 어둡게 |
| 바텀시트 | 아래에서 진입, 배경은 투명도 변화 |
| 체크박스 | 체크 선 그리기 |
| 스위치 | 같은 자리에서 손잡이 이동 |
| 좋아요 | 크기 변화와 짧은 반동 |
| 로딩 | 일정한 속도의 회전 |
| 제목과 설명 | 줄별로 짧은 시차를 둔 등장 |
| 프로젝트 카드 | 호버 반사광과 2px 부상, 눌렀을 때 짧은 크기 변화 |
| 잠금 해제 | 인증 뒤 위로 올라가는 전환 |

진입은 감속, 퇴장은 가속, 제자리 상태 변화는 양쪽 감속을 사용합니다. 주요 동작은 0.2~0.4초이며 운영체제의 동작 줄이기 설정을 따릅니다. 긴 대화의 메시지 목록 전체를 다시 움직여 읽는 위치가 흔들리지 않도록 합니다.

## 검사 방법

눈으로 화면을 확인하는 검사와 실제 좌표 검사를 함께 사용합니다. 화면 폭뿐 아니라 짧은 창 높이와 긴 프로젝트 이름, 많은 프로젝트, 긴 대화를 포함합니다. 스크롤은 움직인 직후와 안정된 프레임을 비교합니다. 합성 자료와 모의 서비스를 사용한 검사는 개인 계정과 실제 외부 기기의 검증과 구분합니다.
