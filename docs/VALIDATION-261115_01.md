# Flowrium 261115_01 검증 기록

검증일: 2026-11-15 (한국 시간)

**Mac 단위 검사 255개와 기능 회귀 38종, 화면 배치 101개 조건을 통과했습니다. Mac 배포 패키지는 격리된 프로필에서 실행과 업데이트 경로를 확인했습니다. Windows도 빌드, 기능 검사와 독립된 환경의 실제 설치 및 업데이트를 통과했습니다. Mac ARM64와 Windows x64 설치본을 공개했습니다.**

공개 버전은 `261115_01`, Electron 내부 버전은 `26.11.1501`입니다. 최종 소스는 `36383ef466605a8ad484d8d78c509892ce27d881`, Mac 패키지 빌드 소스는 `2b9093dd8a8724ab7bd8e97780d42ae9ce371d5d`입니다. 두 커밋 사이에는 다운로드 페이지 검사 파일의 기대값 네 곳만 바뀌었습니다. Mac 패키지의 제품 파일 89개는 최종 소스와 바이트가 일치합니다.

[Mac 구조화 기록](validation/mac-261115_01.json)과 [화면 구성 설명](UI-LAYOUT.md)에 검사 범위와 결과를 기록했습니다. 이전 버전의 실계정 검사 결과를 이번 버전의 모든 기능 검증으로 확대하지 않습니다.

## 검사 조건

기능 검사는 개인 계정과 자료를 분리한 합성 프로젝트와 프로필에서 실행했습니다. 외부 계정, 음성 서버, 모바일 연결은 검사에 필요한 모의 응답을 사용했습니다. 네이티브 Codex 검사는 실제 번들 실행 파일을 통제된 로컬 모의 모델에 연결했습니다. 실제 유료 모델의 응답 품질이나 모든 외부 계정의 동의 절차를 확인한 결과는 아닙니다.

같은 제품 코드에서 전체 회귀를 실행하고, 마지막 채팅 헤더와 업데이트 표시를 보완한 뒤 관련 기능 8종을 다시 확인했습니다. 날짜 버전을 확정한 후 핵심 검사 5종도 재실행했습니다. 기록한 창 크기와 실행 조건의 통과를 모든 기기, 테마 조합, 장시간 실사용의 보증으로 해석하지 않습니다.

## 넓은 채팅과 입력 영역

대화는 기본적으로 본문을 넓게 여는 방식입니다. **대시보드와 나란히 보기**를 선택하면 이전 화면과 입력 상태를 유지한 채 함께 볼 수 있습니다. 대화 목록, 상태 표시, 연결 안내와 이전 기록 제어가 본문을 과도하게 밀어내지 않도록 배치했습니다.

위 수치는 해당 Mac의 합성 대화에서 관측한 값입니다. 전체 페이지의 가로 넘침 없이 긴 코드는 코드 영역 안에서만 가로 스크롤합니다. 일반 문장은 한글 어절을 유지하며 줄바꿈합니다. 낮은 모바일 화면의 제목은 한 줄로 줄이고 전체 제목은 도움말과 대화 관리에서 확인합니다.

이전 메시지 추가, 최신 메시지 이동, 창 크기 변경 뒤 하단 따라가기와 과거 기록을 읽는 동안의 위치 보존을 확인했습니다. 전체 기록 보관과 내보내기는 유지하며 화면에는 최근 기록부터 표시합니다. 합성 메시지 22,000개를 사용하는 긴 대화 회귀도 통과했습니다.

넓은 대화에서도 ChatGPT 이어가기 버튼과 업데이트 안내에 접근할 수 있습니다. 이어가기 주소 전달, 추가 입력 요청, 첨부, 실행 중 지시, 분기와 되감기, 초안과 재시작 복원을 관련 검사에서 확인했습니다.

## 왼쪽 메뉴와 스크롤

이전 설치본에서 프로젝트 영역은 줄었지만 내부 목록이 최소 높이를 유지하면서 아래 그룹과 **128px 겹치는 조건**을 재현했습니다. 로고도 기준 중심에서 왼쪽으로 **5px 치우친 상태**를 확인했습니다.

프로젝트 목록이 할당된 영역 안에서 스크롤하도록 하고 그룹의 높이와 계정 영역을 분리했습니다. 접힘과 펼침에서 메뉴 행의 세로 위치를 유지해 마우스를 올린 직후 클릭해도 다른 항목으로 이동하거나 클릭이 사라지지 않도록 했습니다.

- 네 가지 데스크톱 창 크기와 두 모바일 폭에서 그룹 겹침 0px, 문서 가로 넘침 0px을 확인했습니다.
- 펼친 상태와 접힌 상태의 로고 중심 오차는 0px입니다. 아이콘과 글자의 왼쪽 시작 위치도 확인했습니다.
- 실제 휠 입력으로 프로젝트 목록과 메뉴를 움직인 뒤 정지 직후, 32ms 뒤, 450ms 뒤의 스크롤 위치가 같았습니다.
- 마우스를 올릴 때 행 위치와 스크롤 위치가 유지됐고, 접힌 메뉴의 즉시 선택과 프로젝트 추가를 확인했습니다. 메뉴 고정과 재실행 후 복원도 통과했습니다.

## Mac 패키지와 운영체제 보안

DMG 무결성을 확인했고 ZIP과 DMG의 제품 파일이 같습니다. 최종 패키지의 ARM64, 공개 버전과 내부 버전, 코드 서명 무결성을 확인했습니다. 번들 Node.js, npm, GitHub CLI, 터널 실행기와 Codex를 실행했고 새 프로필은 로그인되지 않은 상태였습니다.

격리한 패키지에서 내장 터미널, PDF와 편집 가능한 PPTX의 생성과 본문 읽기, 기본 앱 도우미의 자체 검사를 통과했습니다. 미공증 새 앱을 업데이트 버튼으로 자동 교체하지 않고 수동 다운로드를 안내하는 경로, 교체 도우미의 준비 확인과 실패 시 이전 앱 복원도 확인했습니다. 넓은 채팅의 모의 업데이트 상태 표시도 통과했습니다.

**Developer ID 서명과 Apple 공증은 없습니다.** 임시 서명의 무결성 검사와 별도로 실행한 실제 Gatekeeper 배포 허용 평가는 종료 코드 3으로 거절됐습니다. 패키지의 격리 실행 성공이 공개 다운로드본의 경고 없는 첫 실행을 뜻하지 않습니다. [터미널 설치 안내](TERMINAL-INSTALL.md)도 운영체제의 보안 설정을 해제하지 않습니다.

격리 프로필 검사와 별도로, 기존 자료가 있는 맥에서도 앱을 정상 종료하고 사용자 자료를 백업한 뒤 터미널 설치기로 교체했습니다. 설정의 `261115_01`, 서명 무결성, 기존 프로젝트와 대화 열기, 기존 ChatGPT 연결과 넓은 대화 화면을 확인하고 앱을 정상 종료했습니다. 유료 AI 요청은 보내지 않았으며, 이 확인이 모든 외부 계정과 기기 권한의 검증을 뜻하지는 않습니다.

## 공개 자료의 개인정보 검사

최종 배포 소스 385개 파일, Mac ASAR 항목 1,418개와 리소스 항목 2,305개에서 민감 경로, 제공한 비공개 표식, 잘못된 압축 경로와 빌드 포함 정책을 검사했습니다. 발견한 항목은 0건입니다. 개인 원문, 대화와 인증 자료를 공개 패키지에 넣지 않는 정책을 확인했습니다.

공급업체의 8MiB 초과 바이너리 11개는 경로를 검사한 뒤 본문 문자열 검사에서 제외했습니다. 알려진 표식의 대조 결과를 모든 바이너리 본문의 완전 조사로 확대하지 않습니다. 공개 검증 문서에는 개인 프로젝트와 대화의 경로, 식별자, 제목, 자료 수량이나 사용자 프로세스 정보를 싣지 않습니다.

## Windows 설치와 업데이트

최종 소스의 Windows 64비트 빌드와 Windows 대상 기능 검사 21개, 최종 배포 필수 검사를 통과했습니다. 정의된 24개 단계 중 Mac 전용 3개는 Windows에서 제외했습니다. 새 채팅, 메뉴와 기능 화면 배치 검사도 실행 로그에서 통과를 확인했습니다. 단위 검사는 255개 중 254개 통과, 실패 0개, 심볼릭 링크 권한에 의존하는 검사 1개 제외이며, 업데이트 도우미 검사 3개도 통과했습니다.

독립된 Windows 환경에서 기존 공개 버전 `0.6.0`을 설치한 뒤 새 날짜 버전의 수동 설치, 재설치, 이전 앱 백업과 합성 자료 및 보내지 않은 초안의 보존을 확인했습니다. 자동 업데이트는 동일 제품 소스에 이전 버전 정보만 적용한 격리 설치본 `261114_99`에서 실제 업데이트 버튼을 눌러 검증했습니다. 다운로드, NSIS 설치 종료 코드 0, 새 버전 `26.11.1501` 재실행 준비와 자료 및 초안 보존을 확인했습니다. 이전 공개 버전에서의 수동 설치와 이 업데이트 시험의 출발점을 구분합니다.

설치 패키지의 내부 실행 파일은 x64입니다. 제품 파일 89개 중 88개는 바이트 또는 일반 줄바꿈 정규화 후 일치하고, HTML 한 개는 연속 CR이 포함된 줄바꿈 표현만 다릅니다. 프런트엔드 자바스크립트와 스타일시트는 바이트가 일치하며 Windows 패키지 개인정보 검사도 통과했습니다.
