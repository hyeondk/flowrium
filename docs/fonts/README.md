# 나눔스퀘어라운드

다운로드 페이지에 네이버 공식 웹폰트 원본 400 / 700 / 800 굵기를 변경 없이 포함합니다. Flowrium 앱과 같은 글꼴을 사용하며 외부 글꼴 서버에 접속하지 않습니다.

- [네이버 공식 글꼴](https://hangeul.naver.com/font)
- [공식 웹폰트 목록](https://hangeul.pstatic.net/hangeul_static/css/nanum-square-round.css)
- [네이버 라이선스 안내](https://help.naver.com/service/30016/contents/18088?osType=PC)
- [저작권과 SIL 라이선스 전문](OFL.txt)
- [원본 주소와 SHA-256](sources.json)

글꼴 이름이나 글리프를 수정하지 않았습니다. 저작권과 재배포 허가를 글꼴 파일과 함께 보관합니다.
