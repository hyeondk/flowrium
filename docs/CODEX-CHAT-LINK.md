# Codex 프로젝트 대화 연결

261114_01에서 이 기기에 저장된 Codex 프로젝트 대화를 찾아 Flowrium에 연결합니다. 기본값은 **같은 대화로 연결**이며 원래 `threadId`를 유지해 기존 문맥으로 이어갑니다. 원래 과거 메시지를 삭제하거나 이동하지 않습니다.

설치 파일별 검사 결과와 사용 조건은 [최종 검증 기록](https://github.com/hyeondk/flowrium/blob/main/docs/VALIDATION-261114_01.md), [전환 상태](REPLACEMENT-STATUS.md), [날짜 버전과 설치 전환](VERSIONING.md)에서 확인하세요. 개인 대화 연결은 각 사용자의 기기에서 실행합니다.

## 연결하기

1. 본인의 ChatGPT 계정으로 로그인하고 진행 중인 작업을 마칩니다.
2. **설정 → 대화와 자료 → 프로젝트 대화 연결**을 엽니다.
3. **Codex 대화 찾기**를 누르고 프로젝트 / 대화 제목 / 메시지와 첨부 정보 / 경고를 확인합니다. 과거 다른 계정의 로컬 기록은 자동으로 소유자를 식별할 수 없으므로 본인 대화만 선택하세요.
4. **같은 대화로 연결** 또는 **독립 사본 만들기**를 선택해 적용합니다. 같은 원본과 방식으로 이미 적용한 대화는 중복 생성하지 않습니다.
5. 연결 기록에서 **대화 열기**를 누릅니다. **보관 원문**으로 이 기기에 저장한 원문을 확인할 수 있습니다.

현재 기기의 Codex가 제공하는 프로젝트 대화를 조회합니다. 다른 기기나 ChatGPT 웹의 모든 대화 목록을 가져오는 기능은 아닙니다. 프로젝트 폴더를 찾을 수 없거나 읽지 못한 대화는 오류를 표시하므로 결과를 확인하고 필요한 항목만 다시 처리하세요.

## 두 가지 방식

| 구분 | 같은 대화로 연결 / 기본값 | 독립 사본 만들기 |
| --- | --- | --- |
| 내부 대화 | 원래 `threadId` 유지 | 새 대화 식별자로 분기 |
| 새 요청 | 원래 대화에 이어 기록 | 사본에 기록 |
| 양쪽 변경 | 작업 종료 후 새로고침해 반영 | 원래 대화와 별개로 진행 |
| 분기 / 되감기 / 압축 | Flowrium에서 제한 | 사본에서 사용 가능 |
| 적합한 경우 | 두 앱을 번갈아 사용 | 원래 대화를 보존하고 별도 작업 |

원래 대화가 실행 중이면 연결한 화면에서 즉시 새 작업을 시작하지 않습니다. 작업이 끝난 뒤 **대화 새로고침**으로 상태를 확인하세요. 실행 중인 원본의 독립 사본은 마지막으로 완료한 작업까지 분기하며, 완료한 작업이 아직 없으면 복사를 보류합니다.

## 양쪽 앱에서 이어 쓰기

한 대화는 **한 앱에서 작업한 뒤 다른 앱으로 전환**합니다. Flowrium의 **대화 새로고침**은 새 본문과 도구 기록을 읽어 기존 표시 기록에 합칩니다. 실행 중이 아닐 때는 열린 연결 대화에서 20초 간격으로, Flowrium 창에 다시 초점을 맞출 때도 갱신을 시도합니다. 원래 앱에서 실행 중인 것으로 가져온 대화는 작업 종료 후 수동 새로고침이 필요합니다. 자동 갱신은 즉시 반영을 보장하는 실시간 공동 편집이 아닙니다.

원래 앱이 대기 상태처럼 보여도 대화의 작성 연결을 보유할 수 있습니다. **원래 앱에서 해당 채팅을 떠나거나 앱을 종료한 뒤 다시 보내세요.** Flowrium은 연결 대화를 실행할 때 전용 실행 연결을 만들고 작업이 끝나면 구독과 연결을 닫아 작성 권한을 반환합니다. 두 앱에서 같은 대화에 동시에 새 요청을 보내는 방식은 지원하지 않습니다.

같은 대화에서 실제 모델을 사용한 양방향 세 차례 왕복과 Codex 앱의 대화 조회 도구를 통한 결과 조회를 확인했습니다. **이미 열려 있는 원래 앱 화면이 즉시 바뀌는지는 확인하지 않았습니다.** 다른 앱에서는 대화를 다시 열거나 해당 앱이 제공하는 갱신 동작으로 확인하세요.

## 기록과 첨부 보관

| 자료 | 처리 범위 |
| --- | --- |
| 사용자와 AI 본문 | 전체 조회한 대화의 표시 가능한 본문 보관 / 갱신 시 중복 방지 |
| 도구 기록 | 명령 실행 / 파일 변경 / 도구 호출을 표시 가능한 기록으로 변환 |
| 원문 | 조회한 대화와 항목의 원문을 프로젝트의 `.flowrium/codex-source/`에 로컬 보관 |
| 첨부 | 원래 정보와 파일 참조를 원문에 보존 / 확인 가능한 지원 로컬 이미지 추가 복사 |
| 사라진 임시 이미지 | 공식 원본 기록과 명시된 이전 기록에서 사용자 본문 / 첨부 경로 / 수와 순서가 같은 이미지 사본을 복구 / 후보가 다르면 보류 |
| 읽지 못한 첨부 | 경고와 원문 참조 보존 / 원격 자동 다운로드나 모든 파일의 원본 복사는 보장하지 않음 |
| 연결 결과 | 적용 / 갱신 / 건너뜀 / 실패를 대화별로 기록 |

임시 원본이 없어 기록에서 복구한 이미지는 **대화 기록의 사본**입니다. 모델 입력 과정에서 해상도나 인코딩이 바뀌었을 수 있으므로 원래 파일과 같은 바이트라고 보장하지 않습니다. 출처와 SHA-256을 로컬 첨부 정보에 보관합니다. 원본과 기록 사본을 모두 찾지 못하면 참조와 경고를 남깁니다. 부족한 첨부는 대화를 다시 찾아 연결하면 메시지를 중복 생성하지 않고 재확인합니다.

원문 / 첨부 / 계정 정보 / 개인 대화는 공개 설치본과 소스 배포 묶음에 넣지 않습니다. 사용자 프로젝트를 별도로 공개할 때도 `.flowrium/`이 포함되지 않도록 확인하세요. 연결은 원래 계정과 기기를 확인하며, 다른 기기로 폴더만 복사한 뒤 원래 대화를 실행하거나 갱신할 수는 없습니다.

긴 기록은 작은 페이지로 나누어 조회하며 큰 응답은 묶음을 줄여 다시 읽습니다. 변경 없는 백그라운드 갱신은 전체 본문을 다시 가져오지 않고, 수동 갱신과 실행 전에는 전체 내용을 대조합니다. 표시 대화는 저장 표현 기준 120MiB까지 지원하고 원문은 별도 보관합니다. 화면에는 최근 기록부터 표시하며 **이전 메시지 100개 더 보기**로 과거 기록을 이어 볼 수 있습니다.

## 실행 제약

- 원래 대화의 지침과 실행 문맥을 유지합니다. 모델 / 생각의 깊이 / 작업 모드는 Flowrium에서 선택할 수 있습니다.
- 원래 앱 전용 동적 도구나 추가 입력은 Flowrium에서 처리할 수 없는 경우가 있습니다. 필요한 작업은 원래 앱에서 이어가거나 Flowrium의 새 업무 대화를 사용하세요.
- 연결 대화는 원본 보호를 위해 Flowrium에서 분기 / 되감기 / 수동 압축 / 자동 압축을 제한합니다. 이 기능이 필요하면 설정에서 독립 사본을 만드세요.
- 계정 전환 / 잠금 / 기기 불일치 / 진행 중인 실행에서는 해당 작업을 거절하거나 갱신을 보류합니다. 표시된 안내를 해결한 뒤 다시 확인하세요.

## 기존 가져오기와의 차이

**작업 기록 → Codex 기록 가져오기**는 프로젝트 경로에 맞는 사용자 메시지와 답변 본문을 한 번 복사하는 기존 기능입니다. 이후 자동 갱신 / 전체 도구 기록 / 첨부 원본 / 원래 실행 문맥 연결은 그 기능의 범위가 아닙니다.

**전체 자료 이관**은 지원하는 자료 묶음의 프로젝트 / 설정 / 기억 / 초안 등을 옮기는 별도 절차입니다. 원래 Codex 대화를 같은 식별자로 이어 쓰려면 이 문서의 **프로젝트 대화 연결**을 사용하세요. [전체 자료 이관](MIGRATION.md)

기존 앱의 삭제는 필요한 대화 / 첨부 / 도구 / 외부 연결 / 백업을 확인한 뒤 결정하세요. 연결 완료만으로 모든 기능의 동일성이나 개인 자료 전체의 이관 완료를 뜻하지 않습니다.
