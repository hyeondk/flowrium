# Flowrium 261115_05 검증 기록

## 우측 통합 탭

이전 설치본에서 결정 요청이 0개이고 완료 알림만 있을 때, 통합 탭에는 알림 개수가 보이지만 그곳에서 알림을 열 수 없는 상황을 재현했습니다. 이제 통합 대화 목록 위의 **프로젝트 알림**을 누르면 중앙에 알림 창이 열립니다. 연결된 알림을 선택하면 해당 프로젝트 대화가 우측에서 열립니다.

합성 프로젝트에서 업무를 다른 대화에 맡겨 완료한 뒤 해당 알림을 선택했습니다. 정확한 원래 대화로 이동하고 읽음으로 바뀌는지, 다른 업무 화면과 통합 대화의 미전송 초안이 유지되는지 확인했습니다. 알림이 한 건도 없는 경우, 모두 읽은 후 읽지 않은 알림만 보는 경우, 좁은 화면에서 버튼과 건수가 겹치지 않는 경우도 검사했습니다.

같은 검사를 맥의 응용 프로그램 폴더에 설치한 05 배포본에서도 실행했습니다. 실행 중인 앱의 버전과 격리된 프로필 경로를 먼저 대조했습니다. [설치된 맥 앱에서 확인한 통합 알림 위치](integrated-notifications-261115_05.png)

## 자료 이관과 전환

이전 형식의 로그인 프로필을 원문 보관 과정에서 읽는 문제를 합성 파일로 재현했습니다. 수정 후에는 원래 상태 폴더와 작업·기억 폴더 선택이 겹쳐도 해당 파일이 읽기 전에 제외됩니다. 다른 프로젝트의 같은 이름 일반 파일, 설정, 대화 원문 보존도 함께 확인했습니다. 공개 패키지 검사에는 해당 로그인 프로필 경로가 포함되면 실패하는 규칙을 추가했습니다. [자료 이관](MIGRATION.md)

과거 Codex 임시 첨부 경고는 원래 참조 파일의 상태를 나타냅니다. 다른 프로그램의 실행기를 제거할 때에는 그 실행기 안에 실제 프로젝트와 사용자 자료가 저장돼 있는지 따로 확인해야 합니다. [전환 상태](REPLACEMENT-STATUS.md)

## 맥 실행과 설치

Apple Silicon에서 최종 소스의 단위 검사 346개, 기능 검사 54개, 완성된 패키지 검사 4개가 통과했습니다. 두 차례 일반 실행과 종료, 미공증 버전의 수동 설치 버튼, 자동 교체 거부와 기존 앱 보존, 내장 터미널을 확인했습니다. 설치된 앱의 버전 정보, 실행 파일, 아이콘, 앱 코드가 최종 압축 파일과 일치했습니다.

디스크 이미지와 압축 파일 안의 앱 구성 3,214개에서 파일 내용, 권한, 심볼릭 링크가 일치했습니다. 내장 도구는 앱 안에서 실행됐습니다. Apple 공증은 없어 공개본의 첫 실행에는 보안 확인이 필요할 수 있습니다.
