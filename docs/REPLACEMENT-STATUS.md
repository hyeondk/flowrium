# Flowrium 사용 범위와 전환 상태

기준일 / 2026-11-14

**Flowrium으로 ChatGPT 기반 프로젝트 업무를 시작할 수 있습니다. 기존 앱의 모든 세부 동작을 동일하게 제공하고 검증한 상태는 아닙니다. 기존 앱의 삭제는 필요한 기능과 자료의 전환을 확인한 뒤 결정하세요.**

**261114_01**은 설정 화면 정리와 Codex 프로젝트 대화 연결을 제공합니다. 다운로드 페이지는 검증 후 공개한 릴리스의 설치 파일만 제공합니다. 운영체제별 검사와 공개 파일 대조의 결과는 [최종 검증 기록](https://github.com/hyeondk/flowrium/blob/main/docs/VALIDATION-261114_01.md)에서 확인하세요. 개인 자료의 연결은 각 사용자의 기기에서 따로 실행합니다.

이전 공개 0.6.0의 전체 자료 이관 / 로컬 음성 서버 관리 / 자동 포트표 / 중앙 보고 팝업은 [0.6.0 검증 기록](VALIDATION-0.6.0.md)에 두 운영체제의 회귀와 설치 검사를 기록했습니다. 이전 버전의 결과를 새 버전의 최종 배포 검증으로 간주하지 않습니다. 기능 이름이나 작업군의 개수만으로 전체 동작의 동일성을 판단하지 않습니다.

같은 Codex 대화는 한 앱에서만 작성합니다. 원래 앱이 대기 상태여도 작성 연결을 보유하면 해당 채팅을 떠나거나 앱을 종료한 뒤 재시도해야 합니다. Flowrium은 연결 대화의 실행 후 전용 연결을 닫아 반환합니다. 연결 대화의 원래 앱 전용 도구 / 분기 / 되감기 / 압축에는 제한이 있으므로 필요한 경우 독립 사본이나 새 업무 대화를 선택합니다. [대화 연결 사용법](CODEX-CHAT-LINK.md)

## 현재 사용할 수 있는 업무

0.5.0에는 통합 채팅 / 일반 대화 / 프로젝트별 ChatGPT 대화 / 이미지와 파일 첨부 / 실행 중 추가 지시 / 내부 대화의 분기와 되감기 / 문맥 압축 / AI 보고와 산출물 / 목표와 기억 / 결정 검토 / 개인 비서 / 팀 업무 / 저장소 작업이 구현되어 있습니다. 프로젝트마다 서로 다른 로컬 폴더를 선택할 수 있습니다.

타입 검사와 빌드, 단위 검사, 격리된 실제 앱 화면 검사, 두 운영체제의 패키지와 설치 검사가 기록되어 있습니다. 실제 ChatGPT 계정에서는 합성한 완료 업무 두 건을 바탕으로 주간 보고를 생성하고 마크다운 파일로 저장하는 경로를 확인했습니다. 추가로 일반 대화와 통합 현황 도구를 실제 ChatGPT에서 확인해 등록 프로젝트 1개 / 점검 문구 3개를 정확히 답하는 경로를 검증했습니다. 실제 계정 검사 몇 건이 모든 기능의 실사용 검증을 뜻하지는 않습니다.

Windows에서는 실제 공개 0.4.0의 업데이트 버튼을 사용한 0.5.0 설치 / 재시작 / 프로젝트와 메시지 / 입력 중 초안 복원이 검증되어 있습니다. Mac에서는 수동 교체와 터미널 설치 후 자료 복원을 검증했습니다. 검사별 조건과 제외 항목은 [0.5.0 검증 기록](VALIDATION-0.5.0.md), 제공 동작은 [기능별 지원 범위](FEATURES.md)를 참고하세요.

## 0.5.0 화면과 대화 변경

아래 항목은 Mac / Windows 실제 앱과 번들 Codex에서 검사했습니다. 모의 모델과 합성 자료를 이용한 검사는 실제 사용자 계정 / 기기의 모든 동작 확인과 구분합니다.

| 변경 | 목표와 확인할 동작 |
| --- | --- |
| 왼쪽 탐색 | 마우스를 올리면 메뉴가 펼쳐지고 벗어나면 접힘 / 메뉴 고정 / 키보드 접근 / 좁은 화면의 조작 |
| 오른쪽 대화함 | 통합 채팅 / 프로젝트 대화 / 일반 대화를 구분하고 목록과 실제 대화를 같은 영역에서 전환 |
| 일반 대화 | 프로젝트를 만들지 않고 대화 시작 / 프로젝트 자료와 외부 도구 접근을 제한 / 계정별 보관 |
| 통합 채팅 | 등록 프로젝트의 제공된 현황을 읽어 설명 / 프로젝트 실행은 결정함에 제안하고 승인 후 해당 프로젝트에서 진행 |
| 실행 상태 | 작업중 / 대기 / 결정을 구분 / 대시보드와 프로젝트 목록과 대화함의 상태 일치 |
| 글자와 배치 | 나눔스퀘어라운드 / 일정한 본문과 제목 줄 높이 / 한글 어절 단위 줄바꿈 / 회색 계열의 구분과 주요 버튼 강조 |
| 움직임 | 스낵바의 아래쪽 이동 / 토스트의 투명도 변화 / 배경을 어둡게 하는 팝업과 바텀시트 / 체크 표시 그리기 / 일정한 로딩 회전 / 제목의 순차 등장 |
| 기존 기능 보존 | 프로젝트 대화 / 첨부 / 초안 / 추가 지시 / 분기와 되감기 / 승인 / 계정 전환 / 잠금 / 좁은 화면의 회귀 검사 |

실행 상태에서 **작업중**은 AI가 실제 작업 중인 경우, **결정**은 실행 허락이나 질문에 대한 답이 필요한 경우, **대기**는 다음 진행이나 추가 입력을 기다리는 경우를 뜻합니다. 완료 업무나 단순히 열어 둔 대화를 모두 대기로 세지 않습니다. 응답의 마지막 문구에 따른 대기 판정도 있으므로 실제 응답 사례와 함께 확인해야 합니다.

공통 움직임은 들어올 때 감속 / 나갈 때 가속, 0.2~0.4초를 기준으로 합니다. 운영체제의 동작 줄이기 설정을 선택한 사용자는 움직임을 줄여 표시하는 대상입니다. 소스에 효과가 정의되어 있다는 것만으로 모든 화면의 적용과 퇴장 동작까지 검증된 것은 아닙니다.
