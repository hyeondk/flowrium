## 현재 사용할 수 있는 업무

프로젝트별 폴더 / 통합 채팅 / 일반 대화 / 프로젝트 대화 / 첨부 / 추가 지시와 취소 / 내부 대화 분기와 되감기 / 문맥 압축 / 목표와 기억 / 결정 검토 / 팀 업무 / 비서와 보고 / 산출물 / 저장소 작업 / 포트표 / 자료 이관을 제공합니다. 기본 저장 위치는 사용자가 프로젝트마다 선택합니다. [기능별 지원 범위](FEATURES.md)

같은 Codex 대화는 원래 식별자를 유지해 연결하거나 독립 사본으로 사용할 수 있습니다. 연결 대화를 열어 두면 창에 돌아올 때와 5초 간격으로 새 기록을 확인합니다. 두 앱은 한 대화에 번갈아 작성합니다. 원래 앱 전용 도구 / 연결 대화의 분기와 되감기 및 압축에는 제약이 있습니다. [대화 연결](CODEX-CHAT-LINK.md)

같은 기기와 계정에 연결한 Codex 대화는 두 방향으로 보관과 복원을 반영합니다. Codex에서 원본을 영구 삭제하면 Flowrium은 복원 가능한 사본을 휴지통에 보관합니다. Flowrium의 영구 삭제 확인 화면에서 원본까지 함께 지울 수 있습니다. 두 앱의 프로젝트 목록 등록 해제는 실제 작업 폴더와 분리됩니다. 지원 범위는 로컬 Codex 대화와 같은 폴더 하나로 확인된 프로젝트입니다. 일반 ChatGPT 웹 대화 기록은 해당 서비스에서 관리합니다. [삭제와 복원](DELETION.md)

## 외부 연결과 배포 준비

| 연결 | 현재 조건 |

| Mac 보안과 업데이트 | Developer ID와 Apple 공증 없음 / 경고 없는 첫 설치와 미공증 앱의 내부 자동 교체를 보장하지 않음 |

Dots의 최초 웹 로그인은 정상 사용 절차입니다. Codex 계정 연결과 공식 웹 로그인은 별개이며 공식 서비스의 접근 자격과 정책이 적용됩니다. Dots의 대화 기록과 통화는 Flowrium 대화 연결의 대상에서 제외됩니다. Google 계정 연결과 API 기능은 03에서 제거했으므로 공개 OAuth 준비를 남은 기능으로 분류하지 않습니다.

## 전환하기 전 확인

1. 필요한 실제 프로젝트를 열어 대화 / 첨부 / 업무 / 보고 / 산출물을 대조합니다.
2. 사용하는 외부 연결을 본인 계정과 기기에서 확인합니다.
3. 원본 자료와 백업을 보존하고 가져온 경로별로 이관 결과를 확인합니다. **Codex 대화 연결**의 과거 이미지 경고는 해당 대화의 원래 파일 위치와 대조합니다. 이전 앱을 제거할 때는 프로젝트 카드, 대화, 첨부, 설정과 기억이 그 앱 번들 안에 저장되어 있는지 별도로 확인합니다. **전체 자료 이관**이 지원하는 설정과 실행 문맥의 범위도 확인하세요. [자료 이관](MIGRATION.md) / [첨부와 남은 확인](REMAINING-261115_03.md)
4. 사용할 설치본에서 재시작과 초안 복원, 계정 전환을 확인하고 해당 버전의 설치와 업데이트 안내를 검토합니다. [릴리스 목록](https://github.com/hyeondk/flowrium/releases)
5. 필요한 동작과 자료가 확인되면 기존 설치본 제거를 결정합니다. 설치본과 원본 자료 및 백업은 각각 따로 관리합니다.

자료를 연결했다는 사실만으로 모든 첨부와 외부 설정의 이전이 끝난 것으로 판단하지 않습니다. Flowrium은 기존 앱이나 원본 프로젝트 폴더를 자동 삭제하지 않습니다.
