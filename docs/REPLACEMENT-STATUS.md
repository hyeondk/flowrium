## 현재 사용할 수 있는 업무

프로젝트별 폴더 / 통합 채팅 / 일반 대화 / 프로젝트 대화 / 첨부 / 추가 지시와 취소 / 내부 대화 분기와 되감기 / 문맥 압축 / 목표와 기억 / 결정 검토 / 팀 업무 / 비서와 보고 / 산출물 / 저장소 작업 / 포트표 / 자료 이관을 제공합니다. 기본 저장 위치는 사용자가 프로젝트마다 선택합니다. [기능별 지원 범위](FEATURES.md)

같은 Codex 대화는 원래 식별자를 유지해 연결하거나 독립 사본으로 사용할 수 있습니다. 연결 대화의 새 기록은 주기적 또는 수동 갱신으로 읽으며 한 앱에서 작업한 뒤 다른 앱으로 전환합니다. 동시 작성 / 원래 앱 전용 도구 / 연결 대화의 분기와 되감기 및 압축에는 제약이 있습니다. [대화 연결](CODEX-CHAT-LINK.md)

기본 삭제는 Flowrium 항목을 휴지통으로 옮깁니다. 연결한 원래 Codex 대화의 보관과 영구 삭제는 별도 영향 확인을 거치며 실제 사용자 원본을 이번 회귀에서 삭제하지 않았습니다. **두 앱 사이의 자동 양방향 삭제 동기화와 ChatGPT 웹 전체 기록의 자동 동기화는 제공하지 않습니다.** Dots도 별도 로그인과 웹 화면이며 Flowrium 대화와 자동 동기화하지 않습니다. [삭제와 복원](DELETION.md)

## 전환하기 전 확인

1. 필요한 실제 프로젝트를 열어 대화 / 첨부 / 업무 / 보고 / 산출물을 대조합니다.
2. 사용하는 외부 연결을 본인 계정과 기기에서 확인합니다.
3. 원본 자료와 백업을 보존하고 이관의 경고와 지원 범위를 확인합니다. 모든 임의 설정과 이전 엔진 실행 문맥을 자동 복원하지 않습니다. [자료 이관](MIGRATION.md)
4. 현재 설치본의 재시작 / 초안 복원 / 계정 전환 / 설치와 업데이트 경로를 확인합니다.
5. 필요한 동작과 자료가 확인되면 기존 설치본 제거를 결정합니다. 설치본과 원본 자료 및 백업은 각각 따로 관리합니다.

자료를 연결했다는 사실만으로 모든 첨부와 외부 설정의 이전이 끝난 것으로 판단하지 않습니다. Flowrium은 기존 앱이나 원본 프로젝트 폴더를 자동 삭제하지 않습니다.
