# Flowrium 기능과 사용 범위

0.4.0의 구현을 기준으로 정리했습니다. 실행한 검사의 환경과 실제 계정·기기 확인 여부는 [검증 기록](VALIDATION-0.4.0.md)에서 구분합니다. 기능 개수나 모의 연결 검사의 통과가 모든 외부 계정과 장치의 동작을 보장하지는 않습니다.

## 프로젝트에서 AI 업무 진행하기

1. 프로젝트를 새로 만들거나 원하는 로컬 폴더를 연결합니다. 프로젝트마다 다른 위치를 선택할 수 있습니다.
2. 목표와 기한을 정하고 역할별 대화를 시작합니다. ChatGPT 계정으로 사용할 모델을 고르며, 조사 깊이와 보고서·발표자료 형식도 지정합니다.
3. AI가 연결한 프로젝트의 실제 기록과 자료를 읽어 작성합니다. 주간 보고와 인계는 독립된 대화와 산출물로 남습니다. 저장소 실행이나 외부 일정 변경은 검토한 제안을 사용자가 승인합니다.
4. 오늘의 할 일과 진척, 결정함과 알림에서 다음 행동을 확인합니다. 자동 감시·정기 보고·팀 자동 배정은 직접 켠 경우에 실행합니다.

## 준비가 필요한 연결

- 사용자마다 본인의 ChatGPT 계정으로 로그인합니다. 사용 가능한 모델과 사용량은 해당 계정에서 확인합니다. 웹 ChatGPT 대화는 주소 연결과 내용 복사 방식으로 이어갑니다.
- 이전 버전에서 이미 만든 내부 대화에는 프로토콜상 새 동적 도구를 추가할 수 없습니다. 해당 대화의 기록과 이어 쓰기는 보존하며, AI 목표·기억·대화 위임 등 새 앱 도구는 새 업무 대화에서 사용합니다.
- Git 저장소 기능은 운영체제 Git과 권한이 있는 원격 저장소를 사용합니다. Node.js / npm / GitHub CLI / 터널 실행기는 설치본에 포함됩니다.
- Google은 본인의 데스크톱 OAuth 클라이언트와 API 활성화, 계정 동의가 필요합니다. 카카오는 본인의 개발자 앱 키와 반환 주소·웹 도메인·나에게 보내기 권한이 필요합니다. 키는 운영체제 안전 저장소에 암호화합니다.
- Mac 메일·캘린더는 사용자가 연결을 켜고 운영체제 권한을 허용해야 합니다. Windows에는 이 Mac 전용 항목을 표시하지 않습니다.
- 휴대폰 연결은 데스크톱과 터널이 실행 중이어야 합니다. 연결을 종료하거나 계정을 바꾸면 기존 주소와 기기 구독의 접근이 끝납니다. 푸시는 브라우저·운영체제의 지원과 알림 권한에 따릅니다.
- 로컬 음성은 사용자가 해당 기기에서 준비한 서버와 모델을 사용합니다. 별도 OpenAI 음성 API를 선택하면 API 키와 해당 API 사용 조건이 적용됩니다. [로컬 음성 준비](LOCAL-VOICE.md)
- 가사 검색과 외부 영상은 서비스에 자료가 있고 재생·조회가 허용된 경우에 사용합니다.

## 설치와 업데이트

Mac ARM64 / Windows x64를 배포합니다. Windows는 앱에서 새 버전 다운로드·검증·설치·재시작을 진행합니다. Mac의 앱 내 자동 교체는 새 버전의 Developer ID 서명과 공증을 확인해야 진행합니다. 미공증 버전은 수동 설치 안내를 표시합니다.

터미널 설치도 SHA-256과 제품·아키텍처를 확인하며 기존 앱을 백업합니다. 보안 설정을 해제하지 않으며 다운로드본의 경고 없는 실행을 보장하지 않습니다. 직접 빌드하는 방법은 [터미널 설치 안내](TERMINAL-INSTALL.md)에 있습니다.
