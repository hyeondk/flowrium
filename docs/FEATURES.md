## 공개 버전 검증

실제 Electron 창의 격리 프로필에서 프로젝트 생성과 복원 / 목표 / 아홉 탭 / 대화 / 산출물 / 보관과 재개 / 팀과 Git 통합 / 잠금과 초안을 검사했습니다. 밝고 어두운 화면의 본문 대비와 작은 화면의 가로 넘침도 검사했습니다.

문서 네 형식을 실제 앱에서 생성하고 본문과 구조를 다시 읽었습니다. 모바일 브라우저에서는 인증 / 기록 나눠 읽기 / 요청과 중단 / 승인 / 일반 질문 / 잠금 복귀를 확인했습니다. 실제 번들 Codex와 로컬 모의 모델을 연결해 질문 응답의 다음 요청 전달도 검사했습니다.

일반 화면 검사의 AI와 외부 서비스 응답은 격리된 모의 연결을 사용합니다. 실제 ChatGPT 계정으로 시험 응답 한 번을 저장했고 YouTube 예제 영상 재생도 확인했습니다. 외부 개인 계정 승인 / 유료 음성 / 실제 마이크 / 휴대폰 외부 회선과 조직별 계정 조합은 별도 검증이 필요합니다.

Windows에서는 공개 구버전의 실제 업데이트 버튼으로 설치 / 재시작 / 대화와 초안 보존을 확인했습니다. Mac에서는 DMG 설치와 계정 연결, 미공증 업데이트 차단 및 수동 설치 안내를 확인했습니다. [0.3.0 상세 검증 기록](VALIDATION-0.3.0.md)

## 직접 검사하기

`npm run check`는 타입 / 빌드와 단위 검사를 실행합니다. `tests/`의 기능별 실제 화면 검사는 격리된 프로필을 사용합니다. `node scripts/verify-downloads.mjs`와 `node tests/download-page-e2e.cjs`는 플랫폼별 공개 파일 연결과 오류 복귀를 확인합니다.
