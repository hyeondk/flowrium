# Flowrium 기능과 사용 범위

261114_01의 소스 구현을 기준으로 정리했습니다. 설정 정리와 Codex 대화 연결을 포함한 Mac / Windows 최종 검사와 설치본 공개를 마쳤습니다. 개인 자료 전체의 이관이나 모든 기능의 실계정 검증을 완료한 것은 아닙니다. [현재 버전의 검증 결과](VALIDATION-261114_01.md)에 검사와 남은 범위를 구분했습니다. 이전 공개 0.6.0의 결과는 [해당 검증 기록](VALIDATION-0.6.0.md)에서 확인합니다. 기능 개수나 모의 연결 검사의 통과가 모든 외부 계정과 장치의 동작을 보장하지는 않습니다.

## 대화 공간과 화면

- 왼쪽 메뉴는 마우스와 키보드로 펼치며 고정할 수 있습니다. 마우스를 벗어나면 본문을 이동하지 않고 접힙니다.
- 오른쪽 대화함에 통합 채팅 / 프로젝트 대화 / 일반 대화를 따로 보관합니다. 프로젝트 업무 중에도 가운데 대시보드와 도구를 유지합니다.
- 일반 대화는 프로젝트 자료와 명령에 접근하지 않습니다. 통합 채팅은 프로젝트 100개 이내의 제공된 현황 / 프로젝트별 최근 대화 15개 / 최근 메시지 4개를 읽으며, 변경 요청은 결정함 승인 후 해당 프로젝트에서 수행합니다.
- 나눔스퀘어라운드 / 일정한 본문과 제어 요소 높이 / 어절 줄바꿈 / 주요 버튼 강조를 적용했습니다. 들어오는 움직임은 감속 / 나가는 움직임은 가속하고 0.2~0.4초를 사용합니다.
- 작업중 / 대기 / 결정은 실제 실행과 요청 상태입니다. 프로젝트 업무의 진행 / 검토 / 완료 단계와는 별도로 표시합니다.
- 설정은 일반 / 보안 / 대화와 자료 / 외부 자료 / 휴대폰 / 음성 / 계정과 모델 / 화면으로 탐색합니다. 본문은 같은 창에서 스크롤하고 좁은 화면에서는 분류를 가로 탭으로 표시합니다.
- 설정 카드의 내부 여백은 기본 20px / 좁은 화면 16px입니다. 주요 실행은 강조하고 보조 행동은 투명한 버튼으로 묶습니다. 320 / 390 / 800 / 1440px 폭에서 문구 여백 / 제어 요소 배치 / 한글 어절 줄바꿈 / 중앙 팝업 / 가로 넘침을 검사했습니다.

## 프로젝트에서 AI 업무 진행하기

1. 프로젝트를 새로 만들거나 원하는 로컬 폴더를 연결합니다. 프로젝트마다 다른 위치를 선택할 수 있습니다.
2. 목표와 기한을 정하고 역할별 대화를 시작합니다. ChatGPT 계정으로 사용할 모델을 고르며, 조사 깊이와 보고서 / 발표자료 형식도 지정합니다.
3. AI가 연결한 프로젝트의 실제 기록과 자료를 읽어 작성합니다. 주간 보고와 인계는 독립된 대화와 산출물로 남습니다. 저장소 실행이나 외부 일정 변경은 검토한 제안을 사용자가 승인합니다.
4. 오늘의 할 일과 진척, 결정함과 알림에서 다음 행동을 확인합니다. 자동 감시 / 정기 보고 / 팀 자동 배정은 직접 켠 경우에 실행합니다.

## 기존 Codex 대화 연결

**설정 → 대화와 자료 → 프로젝트 대화 연결**의 기본값은 원래 `threadId`를 유지하는 같은 대화 연결입니다. 양쪽에서 순서대로 작업하고 새로고침하면 추가 기록을 읽습니다. 한 대화의 동시 작성은 지원하지 않습니다. 원래 앱이 작성 연결을 보유하면 그 채팅을 떠나거나 앱을 종료한 뒤 재시도합니다. Flowrium은 실행 후 전용 연결을 닫습니다.

원래 앱 전용 동적 도구는 실행할 수 없는 경우가 있으며 연결 대화의 분기 / 되감기 / 압축은 제한합니다. 별개로 진행하려면 독립 사본을 선택합니다. 계정과 기기를 확인하고 원문은 로컬에만 보관합니다. 지원하지 않는 첨부는 원문 참조와 경고를 보존하며 모든 파일 원본의 복사를 보장하지 않습니다. [사용법과 상세 제한](CODEX-CHAT-LINK.md)

기존 **작업 기록 → Codex 기록 가져오기**는 본문을 한 번 복사하는 기능입니다. 전체 도구 기록 / 첨부 원본 / 이후 갱신 / 원래 실행 문맥 연결은 제공하지 않습니다. 지원 자료 묶음을 옮기는 [전체 자료 이관](MIGRATION.md)과도 구분합니다.

## 준비가 필요한 연결

- 사용자마다 본인의 ChatGPT 계정으로 로그인합니다. 사용 가능한 모델과 사용량은 해당 계정에서 확인합니다. 웹 ChatGPT 대화는 주소 연결과 내용 복사 방식으로 이어갑니다.
- 이전 버전에서 이미 만든 내부 대화에는 프로토콜상 새 동적 도구를 추가할 수 없습니다. 해당 대화의 기록과 이어 쓰기는 보존하며, AI 목표 / 기억 / 대화 위임 등 새 앱 도구는 새 업무 대화에서 사용합니다.
- Git 저장소 기능은 운영체제 Git과 권한이 있는 원격 저장소를 사용합니다. Node.js / npm / GitHub CLI / 터널 실행기는 설치본에 포함됩니다.
- Google은 본인의 데스크톱 OAuth 클라이언트와 API 활성화, 계정 동의가 필요합니다. 카카오는 본인의 개발자 앱 키와 반환 주소 / 웹 도메인 / 나에게 보내기 권한이 필요합니다. 키는 운영체제 안전 저장소에 암호화합니다.
- Mac 메일 / 캘린더는 사용자가 연결을 켜고 운영체제 권한을 허용해야 합니다. Windows에는 이 Mac 전용 항목을 표시하지 않습니다.
- 휴대폰 연결은 데스크톱과 터널이 실행 중이어야 합니다. 연결을 종료하거나 계정을 바꾸면 기존 주소와 기기 구독의 접근이 끝납니다. 푸시는 브라우저 / 운영체제의 지원과 알림 권한에 따릅니다.
- 로컬 음성은 사용자가 해당 기기에서 준비한 서버와 모델을 사용합니다. 별도 OpenAI 음성 API를 선택하면 API 키와 해당 API 사용 조건이 적용됩니다. [로컬 음성 준비](LOCAL-VOICE.md)
- 가사 검색과 외부 영상은 서비스에 자료가 있고 재생 / 조회가 허용된 경우에 사용합니다.

## 설치와 업데이트

Mac ARM64 / Windows x64를 배포합니다. Windows는 앱에서 새 버전 다운로드 / 검증 / 설치 / 재시작을 진행합니다. Mac의 앱 내 자동 교체는 새 버전의 Developer ID 서명과 공증을 확인해야 진행합니다. 미공증 버전은 수동 설치 안내를 표시합니다.

공개 버전은 `YYMMDD_순번`이며 **0.6.0 이하에서 날짜 버전으로 전환할 때는 한 번 수동 설치**가 필요합니다. 날짜 버전부터 날짜와 순번을 비교합니다. 261114_01의 Windows 실제 설치 / 날짜 버전 업데이트 / 자료 보존과 두 운영체제의 공개 파일 대조 결과는 [최종 검증 기록](VALIDATION-261114_01.md)에서 확인합니다. [버전 규칙](VERSIONING.md)

터미널 설치도 SHA-256과 제품 / 아키텍처를 확인하며 기존 앱을 백업합니다. 보안 설정을 해제하지 않으며 다운로드본의 경고 없는 실행을 보장하지 않습니다. 직접 빌드하는 방법은 [터미널 설치 안내](TERMINAL-INSTALL.md)에 있습니다.
