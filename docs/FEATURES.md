# Flowrium 0.2.0 기능 비교와 검증 범위

비교 대상은 Mac에 설치된 Maestro 0.1.0 실행기와 로컬 원본 소스 개정 `9caac0a`입니다. 앱 실행기는 이미 실행 중인 로컬 서버의 창을 열었습니다. 별도의 브라우저 세션에서 신규 프로젝트 / 설정 / 산출물 / 완료 / 터미널 경로가 모두 로그인 화면으로 이동하는 것도 확인했습니다. 로그인된 개인 기록과 배포 키는 사용하지 않았습니다. [Maestro 공개 페이지](https://lhk228.github.io/maestro-download/)

원본 소스의 `src/routes.tsx`, 사이드바, 프로젝트 탭, 설정, 114개 `src/app/api/**/route.ts` 파일을 기능별로 대조했습니다. 하나의 기능이 여러 API를 사용할 수 있습니다. 아래에서 ‘소스 확인’은 화면과 처리 코드의 연결을 추적했다는 뜻입니다. ‘실행 확인’은 해당 동작과 결과를 실제로 관찰한 경우에만 표시합니다.

### 원본 실행 검증

설치 서버와 별도로 같은 개정의 화면과 서버를 개인 설정 없이 임시 폴더에 빌드했습니다. 비어 있는 시험 프로젝트 폴더로 서버를 시작해 브라우저에서 신규 프로젝트를 생성하고 상세 화면에 진입했습니다. 업무 현황에서 새 업무의 입력점을 확인한 후 기능별 대화를 생성하고 새로고침해 보드에 같은 대화가 나타나는지 확인했습니다. 산출물과 완료 화면에도 진입했습니다.

이후 브라우저에서 새 업무 작성을 취소하고, 새 업무를 생성해 해당 대화를 열고, 완료 기록에서 다시 진행 상태로 돌렸습니다. 시험 문서를 등록한 뒤 본문의 첫 제목과 일치하는 검색 결과, 일치하는 자료가 없는 상태, 다시 검색했을 때의 결과를 확인했습니다. 설정의 폴더 항목과 업데이트 항목 전환, 형상관리 / 시스템 / 터미널 화면 진입도 확인했습니다. 프로젝트 아홉 탭을 링크로 차례로 전환했고, 데스크톱과 모바일의 주요 경로 17개에서 페이지 응답과 화면 부착을 확인했습니다. 경로 진입 검사는 해당 화면의 모든 동작을 실행한 검증과 구분합니다. 원본의 외부 계정 로그인, 실제 사용자 데이터 수정, 원격 저장소 푸시, 구버전 서버 강제 교체는 실행하지 않았습니다.

원본의 프로젝트 설정에 있는 디자인 시안과 회의록 탭은 조사한 개정에서도 준비 중으로 표시됩니다.

## 업무와 산출물 검증

격리된 프로젝트로 파일 선택 / 끌어놓기, 동일 이름의 원본 보존, 텍스트 미리보기를 확인했습니다. 실제 앱에서 마크다운 / HTML / PDF / PPTX를 생성하고, PDF의 한글 본문을 추출했습니다. PPTX의 본문을 확인하고 LibreOffice에서 PDF로 다시 열어 두 페이지의 결과를 확인했습니다. 리서치 업무는 실시간 웹 / 저장된 검색 결과 / 프로젝트 자료를 선택할 수 있고, 기간을 지정한 보고 업무는 해당 기간의 프로젝트 완료 기록과 커밋을 집계합니다.

## 전체 업무와 단축키 검증

실제 Electron 창을 별도 프로필로 실행해 운영체제에서 읽은 CPU, 논리 코어, 메모리를 표시했습니다. 전체 목록에서 대화를 열고 시험용 Codex에 대기 요청을 보낸 뒤, 작업 현황으로 돌아와 요청을 찾아 중단했습니다. 실행 중 건수가 0으로 돌아오는지 확인했습니다. Mac에서 업무 보드 / 새 자유 대화 / 작업 기록 / 설정 단축키와 모달이 열린 상태에서의 입력 보호를 확인했습니다. Windows의 단축키는 같은 화면 테스트를 Windows 실행기에서 별도로 실행할 수 있습니다.

## 다운로드 페이지 검증

공개 페이지와 동일한 정적 파일을 실제 브라우저에서 열고 릴리스 응답을 통제해 확인했습니다. 320 / 390 / 768 / 1280픽셀에서 가로 넘침 없이 어절 단위 줄바꿈과 아이콘이 적용됐습니다. 현재 태그의 두 설치 파일이 준비된 경우, Windows만 준비된 경우, 목록 조회 실패 뒤 다시 확인한 경우를 각각 확인했습니다.

## 직접 재검증하기

- `npm run check`로 화면 타입 검사와 빌드, 격리된 프로젝트의 Codex 연결 / 기록 읽기와 쓰기 / 동시 실행 / 승인 / 충돌 및 복원 테스트를 실행합니다.
- `node scripts/verify-downloads.mjs`로 공개 태그와 자산 이름, Apple Silicon Mac과 Windows x64 다운로드 조건, 예전 Mac 배포 파일 차단, 페이지의 로컬 링크를 검사합니다.
- 패키지 생성, 미로그인 실행, 서명 / 공증, 실제 사용자 설치, 기존 버전에서 새 버전으로 교체 후 재시작은 서로 다른 검증 항목입니다. 각 공개 파일의 서명 상태와 해당 릴리스의 확인 범위는 [릴리스 설명](https://github.com/hyeondk/flowrium/releases)에서 확인하세요.
