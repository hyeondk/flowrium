## 휴대폰 대시보드와 설치

- 인증된 로컬 연결과 브라우저에서 작업중 / 대기 / 결정 목록, 상태별 대화 이동, 열려 있는 대화의 상태 갱신을 확인했습니다. 화면을 보는 동안 2초마다 상태를 요청하고, 다른 화면에서 돌아오면 즉시 갱신합니다. 새 메시지 도착 전후와 350밀리초 뒤에 읽던 메시지 위치는 모두 410.85픽셀이었습니다.
- 320 / 390 / 768픽셀 너비에서 하단 메뉴의 최소 44픽셀 누름 영역, 본문 하단 여백, 키보드 탐색과 동작 줄이기를 검사했습니다. 데스크톱 잠금과 계정에 따른 접근 제한도 확인했습니다. [휴대폰 대시보드](mobile-dashboard-261115_06.png)
- 하단 **설정**에서 도움말 및 홈 화면 설치 안내를 여는 동작, 컴퓨터의 QR 표시와 숨기기, 연결 주소 입력, 아이폰의 Safari 안내, 브라우저 설치 요청의 취소와 대체 안내를 검사했습니다. 홈 상단에는 이 두 안내 버튼이 없습니다. [휴대폰 설정](mobile-settings-261115_06.png)
- 아이폰 17 시뮬레이터(iOS 27.0)의 Safari에서 두 안내를 터치해 열고 닫았습니다. 설정을 불러오는 도중 도움말을 닫을 때 초점이 사라지는 문제도 재현했습니다. 수정 후 10 / 50 / 150 / 350밀리초마다 새 도움말 버튼에 초점이 남아 있었고 스크롤 위치도 유지됐습니다.
- 설정을 편집하는 동안 화면이 갱신되면 선택한 답변 길이가 저장 전 기본값으로 되돌아가는 현상을 재현했습니다. 수정 후에는 새로 선택한 길이와 스위치를 보존하고, 저장이 성공하면 저장한 값이 다음 접속에도 표시됩니다.
- 공개 화면은 합성 프로젝트로 촬영했습니다.

### 아이폰 홈 화면에서 열기

아이폰 17 시뮬레이터(iOS 27.0)의 사파리에서 공유 메뉴의 **홈 화면에 추가**를 누르고 **웹 앱으로 열기**를 켠 상태로 설치했습니다. 홈 화면에 생긴 Flowrium 아이콘을 눌러 독립 웹 앱이 전경에서 실행되는 것까지 확인했습니다. 실물 스마트폰의 홈 설치와 외부 이동통신망은 별도 검증 대상입니다.

## 맥 설치와 실행

Apple Silicon 맥에서 단위 검사 352개, 기능 검사 56개, 완성 패키지 검사 4개, 다운로드 페이지 브라우저 검사 1개가 모두 통과했습니다. 주간업무보고와 업무 마감의 모델 선택, 맥용 설치기의 백업과 재설치, 미공증 업데이트의 수동 설치 전환도 포함합니다.

맥 설치본을 만든 커밋 `b10644a`에서 기능 55개가 첫 실행에 통과했습니다. 개인 비서의 합성 화면을 다시 여는 검사는 병렬 실행에서 한 차례 시간 초과 후 동일 소스의 단독 검사에서 통과했습니다. 휴대폰 설정의 답변 길이를 바꾼 뒤 사용량과 설정을 다시 조회하는 경우, 명시적으로 저장하기 전 선택값이 유지되고 저장 요청과 실제 저장값이 일치하는 것도 설치본에서 확인했습니다.

맥 디스크 이미지와 압축 파일 안의 앱 구성 3,214개에서 내용과 권한, 연결 대상이 일치했습니다. 두 설치본 모두 Apple Silicon 전용이며 임시 서명의 무결성을 확인했습니다. Apple 공증은 없습니다. 응용 프로그램 폴더에 최종본을 설치한 뒤 격리한 프로필로 다시 실행했습니다. 설치된 앱이 제공하는 휴대폰 홈의 상단 버튼은 대시보드 하나였고, 하단 설정에서 두 안내를 열고 닫은 뒤 설정 화면이 갱신될 때도 선택한 안내 행에 초점이 남았습니다.

## 배포 소스와 개인 자료 제외 검사

배포 태그의 커밋은 `519c5f8`입니다. 맥에 설치한 앱을 만든 커밋과의 차이는 잠금 해제 애니메이션 검사와 검증 문서 두 파일입니다. 개선된 검사는 잠금 해제와 로그아웃 창 닫기를 누르기 전에 실제 요소에서 애니메이션 시작을 기록합니다. 맥에서 화면을 450밀리초 늦게 읽어도 시작 이벤트와 키프레임이 정확히 보존되는지 확인했습니다.

공개 소스 압축 파일의 502개 파일에서 내용과 실행 권한이 배포 커밋과 일치했습니다. 윈도우 설치 프로그램 안의 실행 파일이 x64임을 확인했습니다. 윈도우 쪽 앱 파일 89개를 원본과 대조했고, 그중 텍스트 87개는 운영체제 줄바꿈 차이를 통일한 뒤 내용이 일치했습니다. 소스와 두 플랫폼 패키지에서 개인 대화와 경로를 식별하는 표식 10개의 일치는 0건이었습니다. 대형 외부 공급사 바이너리의 내용은 맥 11개, 윈도우 17개가 이 검사에서 제외됩니다.
