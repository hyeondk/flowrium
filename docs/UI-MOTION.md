# 화면 글꼴과 움직임

Flowrium 화면은 공식 나눔스퀘어라운드 글꼴을 앱에 포함해 사용합니다. 첫 실행에도 글꼴 제공 사이트에 연결할 필요가 없습니다. 코드와 터미널은 고정폭 글꼴을 유지합니다.

- 본문: 14픽셀 / 줄간격 1.6
- 기본 입력과 강조 버튼: 높이 40픽셀 / 줄 높이 24픽셀
- 목록 행: 최소 높이 44픽셀
- 페이지 제목: 24픽셀 / 줄 높이 32픽셀
- 부제목: 14픽셀 / 줄 높이 24픽셀
- 문장은 어절 단위로 줄바꿈하며, 항목 구분에는 ` / `를 사용합니다.

화면은 `#081f48 / #163869 / #255a92 / #6f96af / #b7ccde` 팔레트와 아주 연한 파란 배경 / 회색 표면을 사용합니다. 행동 버튼은 둥근 테두리와 일정한 높이를 사용하며 그룹의 오른쪽에 배치합니다. 왼쪽 메뉴는 아이콘과 글자를 왼쪽에 정렬합니다.

## 공통 구성 요소

소스는 `src/ui-motion.tsx`, `src/ui-motion.css`에 있습니다. 스타일은 `src/main.tsx`에서 기존 공통 스타일 다음에 불러옵니다.

- `usePresence(open, durationMs = 240)`: `{ present, phase }`를 반환합니다. `present`로 마운트를 유지하고 `phase`를 `data-phase`에 전달합니다. 단계는 `enter`, `idle`, `exit`입니다.
- `MotionPresence`: `open`과 선택적인 `durationMs`, `phase => 화면` 형태의 자식 함수를 받습니다.
- `MotionOverlay`: `open`, `onClose`, `label`, `children`, 선택적인 `kind="popup" | "sheet"`를 받습니다. 초점 이동과 복구 / 탭 순환 / Escape 닫기를 포함합니다.
- `Toast`, `Snackbar`: `message`, 선택적인 `onClose`, `tone="info" | "success" | "error"`, `action`을 받습니다. 빈 메시지로 바꾸면 마지막 내용을 유지한 채 퇴장합니다.
- `AnimatedCheckbox`: 기본 체크박스 입력과 같은 속성을 받습니다. 실제 입력을 유지하므로 라벨 클릭 / 키보드 / 참조 / 기존 변경 이벤트를 그대로 사용합니다. 체크 선은 장식용 SVG입니다.

개별 화면에서 종료 애니메이션이 필요한 컴포넌트를 `{open && ...}`로 즉시 제거하지 않습니다. `MotionPresence` 또는 `usePresence`로 종료까지 유지합니다. 지속 시간을 바꿀 때는 200~400밀리초 범위에서 훅과 해당 요소의 `--motion-duration`을 함께 설정합니다.

## 검증

`node tests/ui-motion-e2e.cjs`는 격리한 Electron 창에서 공식 글꼴 4종 / 실제 체크박스 라벨과 키보드 / 팝업 초점 / 등장과 퇴장 / 닫히는 중 재열기 / 스낵바와 토스트 / 하단 시트 / 검색과 개인 비서 팝업 / 동작 줄이기를 검증합니다. 임시 창과 프로필 / 검증 소스는 종료 시 정리합니다.

글꼴의 공식 출처와 해시값 / 저작권과 재배포 허가는 `electron/mobile/fonts/sources.json`, `README.md`, `OFL.txt`에 보관합니다. [네이버 공식 글꼴 소개](https://hangeul.naver.com/font)와 [공식 이용 안내](https://help.naver.com/service/30016/contents/18088?osType=PC)를 확인할 수 있습니다.

팝업은 `ModalPortal`을 통해 문서 본문에 표시하므로 부모 화면의 이동·확대 애니메이션에 위치가 종속되지 않습니다. 중앙 팝업과 아래쪽 시트를 구분합니다. 검색 / 대화 관리 / 주간업무보고 / 업무 마감은 중앙 팝업을 유지합니다.

`AnimatedSwitch`는 실제 입력과 `role="switch"`를 보존하며 라벨 클릭 / 키보드 조작 / 초점 표시를 지원합니다. 항목 선택과 위험 확인에는 체크박스를 유지합니다. `LikeButton`은 답변의 반응을 프로젝트 대화 기록에 저장합니다.
