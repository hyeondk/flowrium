# 모바일 하단 메뉴와 업데이트 검증

## 화면과 조작

아이폰 17 시뮬레이터(iOS 27.0)의 웹 엔진에서 실제 터치 제스처로 홈에서 설정, 설정에서 홈으로 이동했습니다. 두 방향의 79프레임을 각각 기록했습니다. 266픽셀 구간에서 선택 표시가 따라간 위치는 각각 60개와 63개였습니다. 손을 놓으면 탭이 한 번만 바뀌었습니다. 공개 예시는 합성 프로젝트로 촬영했습니다. [아이폰 홈](mobile-dashboard-261115_09.png) / [아이폰 설정](mobile-settings-261115_09.png)

모바일 브라우저에서 화면 폭 320 / 390 / 768픽셀을 검사했습니다. 세로로 밀면 본문을 읽을 수 있고, 글자 크기를 200%로 키워 탭이 화면을 넘으면 바 자체를 좌우로 밀어 마지막 메뉴에 접근할 수 있었습니다. 트랙패드 관성 입력, 방향키, 동작 줄이기도 확인했습니다. 대화 내용이 자동 갱신될 때 읽고 있던 메시지의 위치는 갱신 전후와 350밀리초 뒤 모두 411.22픽셀이었습니다.

320픽셀 창에 고정 스크롤바가 16픽셀을 차지하는 경우 본문과 가용 폭은 모두 304픽셀이었습니다. 기존 검사는 본문과 창 전체 폭을 비교해 실패했습니다. 가용 폭을 기준으로 바꾼 뒤 같은 조건에서 통과했고, 일부러 만든 8픽셀 가로 넘침은 검사가 잡아냈습니다.

화면의 색상값을 기준으로 계산한 명암비는 밝은 화면에서 본문과 연파랑 배경이 11.78 대 1, 흰 글자와 짙은 파랑 버튼이 7.42 대 1이었습니다. 어두운 화면에서는 본문과 배경이 14.41 대 1이었습니다.

390픽셀 브라우저에서 홈과 설정의 실제 적용 색상도 확인했습니다. 밝은 모드의 홈 카드와 업데이트 버튼은 각각 `#D5E7F5`와 `#225984`, 어두운 모드에서는 `#395972`와 `#B2D5F0`였습니다. 하단 바 선택 표시의 그라데이션도 두 모드 모두 파란 계열이었습니다.

## 업데이트와 개인 연결

아이폰 설정에서 현재 버전 확인, 새 버전 검색, 다운로드 및 적용, 새 화면에서 설정 복귀를 검사했습니다. 다음 버전은 시험용 공개 메타데이터와 화면 파일로 제공했습니다. 실제 다운로드 및 검증 코드와 웹 엔진을 사용했습니다. 최신 버전, 네트워크 오류 후 재시도, 컴퓨터 업데이트가 먼저 필요한 상황도 확인했습니다.

서로 다른 컴퓨터를 나타내는 두 서버에 각각 연결하고 상대의 연결 키로 접근이 거부됨을 확인했습니다. 잠금과 연결 종료 뒤 접근 차단, 같은 파일의 중복 다운로드 방지, 지문이 달라진 파일의 적용 거부, 손상된 캐시의 복원도 검사했습니다.

## 맥 설치본

애플 실리콘 설치본 두 종류의 3,214개 항목에서 파일 내용, 링크, 권한이 일치했습니다. 앱의 임시 서명과 내장 터미널 실행을 확인했고 새 프로필은 로그아웃 상태였습니다. 애플 공증은 적용하지 않았습니다.

최종 소스의 맥 단위 검사 361개가 모두 통과했습니다. 시뮬레이터와 동시에 실행했을 때는 메모리 사용량 상위 80개 프로세스에 검사 프로세스가 포함되는지 확인하는 기존 항목이 실패했습니다. 시뮬레이터 종료 뒤 해당 검사와 전체 검사를 다시 실행했습니다.

## 윈도우 설치본

윈도우 단위 검사 361개 중 359개가 통과했고 환경별 검사 2개는 건너뛰었습니다. 모바일 업데이트와 하단 바를 포함한 기능 검사도 통과했습니다. [기능 검사 기록](https://github.com/hyeondk/flowrium/actions/runs/43720776316/job/132832074253)

별도 윈도우에서 0.6.0 설치본을 새 버전으로 교체하고 프로젝트와 대화 초안 복원을 확인했습니다. 261115_08에서는 앱의 업데이트 버튼을 눌러 파일 교체 후 261115_09로 재시작하는 것을 확인했습니다. 배포 파일 안의 실행 프로그램은 64비트였고, 모바일 화면과 관련 코드 18개의 내용이 배포 커밋과 일치했습니다. [설치 및 재시작 기록](https://github.com/hyeondk/flowrium/actions/runs/43720776316/job/132835610110)

## 공개 배포 확인

정식 공개 후 비로그인 상태에서 설치 및 검증 파일 10개의 다운로드가 가능했고 모두 배포 초안에서 확인한 크기와 SHA-256에 일치했습니다. 공개 소스 521개와 모바일 화면 파일 14개의 내용을 배포 커밋과 비교했습니다. 격리된 모바일 업데이트 모듈에서 이전 버전 번호로 시작해 공개된 화면 묶음을 내려받고 검증한 뒤 스크립트와 스타일이 적용되고 최신 상태로 표시되는지 확인했습니다. [배포 파일 검증값](validation/release-261115_09.json)
