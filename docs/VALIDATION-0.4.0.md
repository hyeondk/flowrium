# Flowrium 0.4.0 검증 기록

검증일 / 2026-11-13

현재 Mac 패키지와 Windows 배포 검증을 진행하고 있습니다. 아래 완료한 검사와 외부 환경의 미확인 조건을 구분합니다. 원격 실행과 공개 파일 확인 결과는 배포를 마친 뒤 갱신합니다.

## 로컬 소스와 실제 화면

- 타입 검사와 프로덕션 빌드 / 전체 단위 검사 145개를 통과했습니다. 배포 의존성의 알려진 취약점은 `npm audit --omit=dev`에서 0개입니다.
- 실제 Electron의 격리 프로필로 첨부 / 캡처 / 파일 끌어놓기 / 프로젝트별 초안 / 실행 중 지시와 취소 / 분기·되감기 입력 복원을 검사했습니다.
- 실제 번들 Codex 앱 서버에 모의 Responses 서버를 연결해 이미지 입력, 동적 앱 도구와 도구 응답, 선택 요청의 실제 내부 분기·되감기, 원대화와 도구 결과 보존을 검사했습니다. 구조화 분석은 권한 프로필을 확인하고 셸·외부 도구를 실행하지 않는 경로로 검사했습니다.
- 프로젝트 보드와 순서 / 전체 검색 / 목표의 상하 연결·진척·이월·반복 / 여러 저장소 / HTML 미리보기·수정·재변환·삭제 복원 / 압축 보관·복원을 실제 화면과 저장 파일에서 확인했습니다.
- 오늘의 목표와 기한, 시작·완료 그래프는 실제 저장한 시험 기록을 집계합니다. 밝고 어두운 테마 본문 대비와 768 / 390 / 320픽셀의 대시보드, 320픽셀 상세 탭을 검사했습니다. 어두운 테마에서 재현한 대비 오류를 수정하고 재검사를 통과했습니다.
- 문서 HTML에서 PDF와 편집 가능한 PPTX를 생성하고 한국어 본문 / 표 / 발표자 메모 / 두 번째 슬라이드를 다시 읽었습니다. 스크립트 차단과 PDF 폰트 제어문자 정리도 검사했습니다.
- 대화 간 요청의 사용자 승인 / 대기와 결과 회신 / 통합 결정함 / 알림 읽음 / 비서의 실제 AI 보고 / 예약 복원 / 팀 자동 배정·재검수·통합 / AI 기억 도구·선택 가져오기·이동을 검사했습니다.
- Git 통합 계획·실패 재개·원격 변경 거절·인덱스 백업 복원을 격리 저장소로 검사했습니다. 프로세스 분석에는 명령행을 전달하지 않으며, 직접 만든 시험 프로세스 중 선택한 하나만 종료하고 미선택·자기 프로세스를 보존했습니다.
- 기존 대화 / 잠금 / 계정 전환 / 미전송 초안 / 기억 / 추가 질문 / 역할별 Git 작업 폴더 / 기존 문서 내보내기의 화면 회귀를 통과했습니다.

## 실제 ChatGPT 계정

본인의 기존 로그인을 정상적으로 사용하고 추가 API 키 없이, 새 임시 프로젝트에 합성한 완료 업무 2개를 넣어 주간업무보고를 생성했습니다. 실제 모델 `gpt-6.1-sol`이 산출물 도구를 1회 호출하고 결과를 받은 뒤 프로젝트의 마크다운 파일을 저장하는 경로를 23초에 통과했습니다. 인증을 복사하거나 기존 프로젝트·대화를 변경하지 않았습니다.

## 외부 자료와 모바일

- Google 여러 캘린더 / 전체 메일 본문 / 표 읽기와 실제 CSV 파일 저장 / 일정 생성·수정·삭제 검토 / 취소 / ETag / 단회 변경을 가짜 계정과 실제 앱 화면으로 검사했습니다.
- Mac 일정 도우미를 실제 Swift / EventKit으로 컴파일하고 계정에 접근하지 않는 자체 검사를 통과했습니다. 기본 앱 연결의 명시적 활성화 / 변경 개정 / 계정 분리는 모의 운영체제 응답으로 검사했습니다.
- 모바일 실제 브라우저에서 단회 링크 교환 / 첨부·추가 지시·취소 / 팀 생성·배정·통제 / 비서·결정·예약 / 모델·사용량 / 서비스워커와 기기 알림 설정 / 잠금·계정 분리를 검사했습니다. 링크 만료·재사용·연결 종료·계정 변경과 금지 명령도 검사했습니다.
- 웹 푸시는 구독의 암호화 / 전송 종류 / 중복 방지 / 만료 기기 정리 / 안전한 공급자 주소를 모의 전송으로 검사했습니다. 실제 외부 푸시를 개인 기기로 발송하지 않았습니다.
- 카카오 로그인 상태·PKCE·비밀 비노출 / 본인 채팅 전달 / 메일 허용목록·새 요청·중복·시간·횟수 제한을 모의 연결과 실제 설정 화면으로 검사했습니다. 실제 카카오·메일 메시지를 보내지 않았습니다.
- 로컬 음성은 실제 127.0.0.1 HTTP와 WAV 표본 / 연속 구간·무음 / 호출어 / 검토 기본값 / 명시적 자동 전송 / 처음 만든 대화와 기존 대화 / 화면 이동 뒤 늦은 결과 폐기 / 실제 Chromium WAV 디코더의 무음 재생·중단을 검사했습니다.
- 동기 가사는 합성 LRC와 모의 플레이어를 사용해 검색 / 현재 줄 / 줄을 눌러 이동 / 메모 보존 / 전체 화면 스크롤 안정성을 검사했습니다.

## 패키지와 설치 / 진행 중

- Apple Silicon Mac과 Windows x64의 새 패키지를 각각 해당 운영체제에서 검사합니다.
- Windows는 공개 0.3.0의 실제 업데이트 버튼에서 새 버전 설치·재시작과 자료 보존을 검사합니다.
- Mac은 미공증 업데이트의 자동 교체 차단과 수동 설치 안내를 유지합니다. 공증이 없는 다운로드본의 경고 없는 설치는 보장하지 않습니다.
- Mac 터미널 설치는 실제 ARM64 시험 앱으로 서명 무결성 / 기존 앱 백업 / 실행 중 거절 / SHA 변조·경로 탈출·외부 링크·Intel 위장 차단 / 소스 안전 추출을 통과했습니다. Windows 설치기는 Windows 러너 검증을 대기합니다.

## 외부 환경의 확인 조건

실제 Google·카카오 계정의 동의와 공급자별 정책 / 개인 Mac의 메일·캘린더 권한 / 유료 음성 API / 개인 마이크 장치와 설치된 음성 모델 / 실제 휴대폰 외부 회선과 푸시 수신은 위 모의 검사에 포함되지 않습니다. 사용자의 계정·권한·서버·기기 설정이 필요합니다. 이전 내부 대화에 새 동적 도구를 추가하는 것은 프로토콜 제약이 있어 새 업무 대화에서 사용합니다.
