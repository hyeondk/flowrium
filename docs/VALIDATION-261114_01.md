## Codex 프로젝트 대화 연결

기본 연결 방식은 원래 `threadId`를 유지합니다. 본문과 도구 기록 / 첨부 참조와 지원 로컬 이미지 / 로컬 원문 / 중복 방지 / 수동 새로고침 / 20초 간격과 창에 돌아올 때의 갱신 / 독립 사본 선택을 제공합니다. 실제 모델로 같은 대화를 양방향 세 차례 이어 쓴 뒤 원래 앱의 대화 조회 도구에서도 모든 왕복 기록을 확인했습니다.

이미 열려 있는 원래 앱 화면이 자동으로 캐시를 갱신하는지는 확인하지 않았습니다. 같은 대화의 동시 작성도 지원하지 않습니다. 원래 앱이 대기 상태라도 작성 연결을 보유하면 해당 채팅을 떠나거나 앱을 종료한 뒤 재시도해야 합니다. Flowrium은 연결 대화의 실행이 끝나면 전용 실행 연결을 닫아 반환합니다.

원래 앱 전용 동적 도구와 추가 입력에는 제한이 있습니다. 연결 모드의 분기 / 되감기 / 압축은 제한하므로 필요한 경우 독립 사본을 선택합니다. 계정과 기기 검사도 적용합니다. 연결한 대화는 앱을 재시작한 뒤에도 다시 열리는지 확인했습니다. 일부 첨부 이미지는 파일을 확보할 수 없으므로 전체 자료 이관 완료로 해석하지 않습니다. [사용법과 상세 제한](CODEX-CHAT-LINK.md)

## 첨부 이미지 복구와 경계

임시 이미지 파일이 없을 때 공식 대화 기록에 저장된 모델 입력용 이미지 사본을 확인하는 경로를 추가했습니다. 합성 검사 12개, 첨부 재확인과 실제 앱 검사를 통과했습니다. 한글 파일명의 NFC / NFD 정규화 차이 때문에 같은 경로를 다르게 비교하던 조건을 실제로 재현하고 비교를 수정한 뒤 회귀 검사를 통과했습니다.

복구한 것은 **모델 입력용 이미지 사본**일 수 있으며 원래 첨부 파일과 동일한 해상도나 바이트를 보장하지 않습니다. 읽을 수 있는 파일과 검증된 사본을 구분하고, 파일을 확보하지 못한 항목은 원문 참조와 경고를 보존합니다. 첨부 재확인 기능은 이미 연결한 대화에서도 다시 복구를 시도할 수 있게 하며 모든 누락 파일이 복구된다는 뜻은 아닙니다.

| --- | --- |

## Mac 최종 패키지 검사

Mac 패키지의 Apple Silicon ARM64 / 코드 서명 무결성 / DMG 체크섬을 확인했습니다. ZIP과 DMG 안의 `app.asar`가 같고 제품 코드 71개의 바이트가 최종 소스와 일치합니다. 번들 Node.js / GitHub CLI / Codex 실행과 새 프로필의 미로그인 상태, 패키지의 내장 터미널과 PDF / PPTX 변환을 통과했습니다. 최종 재빌드에서도 기본 실행 / 내장 터미널 / 실제 업데이트 버튼 / 미공증 앱의 자동 교체 거절과 실패 복원 / ARM64와 서명 무결성을 다시 통과했습니다.

실제 Mac 앱의 업데이트 버튼은 미공증 새 앱을 자동 교체하지 않고 수동 설치 페이지를 여는 경로를 통과했습니다. 운영체제 교체 도우미의 준비와 실패 시 이전 앱 복원도 통과했습니다. 이는 미공증 앱의 자동 교체가 허용되었다는 뜻이 아닙니다.

**Developer ID 서명과 Apple 공증은 없습니다.** 실제 Gatekeeper 평가는 종료 코드 3 / 거절입니다. 코드 서명 무결성 검사와 로컬 실행 검사의 통과를 공개 다운로드본의 경고 없는 첫 실행으로 해석하지 않습니다. 터미널 설치기도 운영체제 보안 정책을 해제하지 않습니다.

공개 버전은 `YYMMDD_순번`입니다. 0.6.0 이하의 기존 업데이트 코드는 날짜 태그를 인식하지 못하므로 날짜 버전으로 전환할 때 한 번 수동 설치가 필요합니다. 이후 날짜 버전은 날짜와 순번으로 업데이트를 확인하며 미공증 Mac은 계속 수동 설치를 안내합니다. [버전 규칙](VERSIONING.md) / [터미널 설치](TERMINAL-INSTALL.md)

0.6.0에서 날짜 버전으로의 전환은 한 번 수동 설치하는 경로이며, 날짜 버전끼리의 실제 업데이트 버튼 검사와 구분합니다. 검사 결과와 제외 범위는 [Windows 구조화 기록](validation/windows-261114_01.json)에 기록했습니다. 공개 설치본의 크기와 SHA-256도 CI 산출물 및 해시 목록과 대조했습니다. Windows 제품 파일 88개는 바이트 또는 일반 줄바꿈 정규화 후 일치하며, HTML 1개는 줄바꿈의 연속 CR 표현만 다릅니다. 프론트 JavaScript / CSS는 바이트가 같고 제품 파일 누락과 추가는 없습니다.

Mac과 Windows의 앱 / 설치 / 업데이트 검증은 위 범위에서 완료했습니다. [261114_01 릴리스](https://github.com/hyeondk/flowrium/releases/tag/261114_01)를 공개했고 최종 설치 파일 9개의 크기와 SHA-256을 대조했습니다. [배포 대조 기록](validation/release-261114_01.json)과 [전환 상태](REPLACEMENT-STATUS.md)에 사용 조건을 기록했습니다. 개인 자료 전체의 실제 이관은 일부 첨부 원본을 확보하지 못한 범위가 있어 완료로 기록하지 않습니다.
