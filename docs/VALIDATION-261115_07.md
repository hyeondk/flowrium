# 다음 작업 추천 검증

모델 응답을 12초 늦추고 데스크톱 채팅에서 추천 버튼을 눌렀습니다. 이전 공개판은 10초가 지난 뒤에도 입력창에 추천이 없었습니다. 수정본은 **1.006초**에 직전 답변에서 제안한 작업을 입력 미리보기와 선택 버튼으로 표시했습니다. 선택한 문구는 전송 전 초안에만 추가됐습니다.

후속 모델 응답이 도착해도 읽던 후보의 순서와 직접 입력한 초안이 유지됐습니다. 다른 대화로 이동한 뒤 늦은 추천이 나타나는지, 모델 오류 뒤 명시된 제안을 계속 쓸 수 있는지, 근거 없는 완료 보고에서 문구를 임의로 만드는지도 검사했습니다. 여섯 창 크기에서 추천 버튼, 전체 문구 팝업, 입력창 높이와 대화 스크롤을 확인했습니다.

## 실제 모델 응답 시간

개인 프로젝트를 포함하지 않는 합성 사례로 GPT-6.1 Sol을 호출했습니다. 각 요청은 기록에 남지 않는 독립 분석 대화를 사용했습니다. 아래 시간은 서버에 요청한 뒤 검증을 통과한 완성 추천이 도착할 때까지입니다.

| 사례 | 개선 전 | 개선 후 |
| --- | ---: | ---: |
| 첫 번째 | 10.476초 | 9.620초 |
| 두 번째 | 측정하지 않음 | 9.243초 |
| 세 번째 | 측정하지 않음 | 13.324초 |

세 번째 사례는 모델의 첫 글자가 12.675초에 도착했습니다. 직전 답변에 구체적인 후속 작업이 없는 대화에서는 새 모델 응답 시간이 첫 표시 시간을 결정합니다.

실제 맥 화면에서 합성 일반 대화와 GPT-6.1 Sol을 연결한 별도 검사에서는 버튼 클릭부터 직전 답변의 첫 후보를 그린 프레임까지 **1.004초**, 새 모델 후보가 선택 가능해진 프레임까지 **15.679초**였습니다. 선택 전 입력창의 초안은 비어 있었습니다.

## 아이폰 외부 연결

개인 계정과 프로젝트를 연결하지 않은 읽기 전용 합성 대시보드에서 실제 임시 터널을 열었습니다. 발급 직후에는 공개 DNS가 새 주소를 찾지 못했습니다. 같은 연결을 유지한 뒤 공개 HTTPS 주소에서 인증 없는 요청의 거절과 연결된 기기의 작업중 / 대기 / 결정 세 상태를 확인했습니다. 작업중과 대기를 해제한 뒤 다시 조회해 변경이 반영됐고, 데스크톱 잠금 뒤에는 접근이 차단됐습니다. 시험 연결은 종료했습니다. 아이폰 실물의 이동통신망과 푸시 수신은 별도 검증 대상입니다.

## 맥 설치본

맥용 디스크 이미지와 압축 파일의 내부 앱 구성 3,214개를 대조했습니다. Apple Silicon 전용 아키텍처, 임시 서명 무결성, 별도 프로필 실행과 내장 터미널을 확인했습니다. 압축 파일에서 꺼낸 앱에서도 클릭 후 1.006초에 직전 답변의 추천이 표시됐습니다. 최종 소스의 맥 단위 검사 357개가 모두 통과했습니다. 애플 공증은 없습니다.

## 윈도우 설치본
