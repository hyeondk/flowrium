# Flowrium 0.4.0 구현과 검증 진행표

28개 작업군을 구현하고 Mac / Windows의 기능별 화면·패키지·설치·업데이트 검증을 마쳐 0.4.0으로 배포했습니다. 실제 외부 계정·장치가 필요한 조건은 별도로 구분합니다. 상세 근거는 [0.4.0 검증 기록](VALIDATION-0.4.0.md)에 정리했습니다.

## 적용 조건

- 제목은 Flowrium만 표시합니다. 공개 화면과 문서에는 다른 프로그램을 참고했다는 소개와 링크를 표시하지 않습니다.
- 사용자는 프로젝트 / 기간 / 사유 / 짧은 메모와 모델을 선택합니다. 보고서 / 인계 / 문서 / 목표 정리는 연결한 ChatGPT 모델이 실제 자료를 읽어 생성하고, 필요한 경우 사용자 검토를 거쳐 저장합니다.
- 대시보드는 실제 기록의 오늘 할 일 / 기한 / 결정 대기 / 업무 현황 / 완료 및 커밋 추이를 표시합니다. 예시 수치를 사용자 자료처럼 표시하지 않습니다.
- 주기 감시와 자동 팀 운영은 사용자가 켠 경우에만 실행합니다. 잠금 / 계정 변경 / 업데이트 중에는 새 작업을 시작하지 않습니다.
- 한국어 어절 줄바꿈 / 항목 구분자 ` / ` / 숫자 입력의 휠 증감 방지를 유지합니다.
- 터미널 설치는 출처와 SHA-256을 확인하고 기존 자료를 보존합니다. Mac의 보안 설정과 격리 속성을 자동으로 해제하지 않습니다. 직접 빌드 방법도 제공합니다.

## 최종 공개 기준

기능별 실제 화면 / 저장 결과 / 재실행 복원 / 취소와 충돌을 확인합니다. 실제 번들 Codex와 모의 모델의 규격 검증, 실계정 호출과 외부 기기 검증은 구분합니다. Mac ARM64와 Windows x64에서 패키지 / 새 프로필 / 설치 / 업데이트와 기존 자료 보존을 검사하고 공개 체크섬과 다운로드 연결까지 대조합니다. 모든 작업용 앱과 임시 파일은 종료 및 정리합니다.
