# Flowrium 개발 계획

Flowrium은 각 사용자가 자기 ChatGPT 계정으로 로그인하고 프로젝트별 독립 대화에서 업무를 진행하는 데스크톱 앱입니다. 프로젝트마다 원하는 로컬 폴더를 선택합니다.

## 0.4.0 반영 결과

0.3.0에서 정리한 28개 작업군을 0.4.0에 반영했습니다. 채팅 첨부 / 실행 중 추가 지시 / 실제 내부 분기·되감기 / AI 보고와 위임 / 목표·산출물 / 여러 저장소 / 비서·팀 / 외부 자료와 모바일 / 로컬 음성·가사까지 기능별 화면과 저장 결과, 재실행 및 운영체제 패키지를 검사했습니다. [기능과 준비 조건](FEATURES.md) / [구현 결과](IMPLEMENTATION-0.4.0.md)

실제 계정 승인이 필요한 기능은 모의 연결 검사와 실계정 검사를 구분합니다. 지원하지 않는 상태를 완료로 표시하지 않습니다. [0.4.0 검증 기록](VALIDATION-0.4.0.md)

## 배포

Apple Silicon Mac과 Windows x64를 제공합니다. 운영체제별 설치 파일과 업데이트 / 재시작 / 기존 대화 및 초안 보존을 검사합니다. 배포 파일에 개발자의 인증 정보와 개인 자료를 담지 않습니다.

공증되지 않은 Mac 파일은 Apple이 확인한 개발자로 표시되지 않습니다. 출처와 확인값을 검사하는 터미널 설치와 직접 빌드 방법을 제공하되 운영체제의 보안 설정을 끄지 않습니다.

## 독립 실행과 데이터 보존

설치본에 Electron / 플랫폼용 Codex / 가상 터미널 / Node.js / npm / GitHub CLI / Cloudflare 실행기를 포함합니다. 사용자 자료는 선택한 프로젝트의 `.flowrium/`과 산출물 폴더, 기기별 앱 데이터 폴더에 저장됩니다. 앱 교체와 사용자 자료 삭제는 분리합니다.
