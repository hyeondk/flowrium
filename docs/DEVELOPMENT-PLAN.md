# Flowrium 개발 범위와 사용 시점

2026년 11월 13일 기준입니다. Flowrium은 각 사용자가 자기 ChatGPT 계정으로 로그인하고, 자신의 프로젝트 폴더에서 대화를 나누어 작업하는 데스크톱 앱입니다. 사용자가 정한 업무만 시작합니다. 이번 버전의 AI 연결은 Codex와 ChatGPT입니다. Claude 연결은 후속 버전으로 미뤘으며 별자리 화면은 제외합니다.

## 만들 기능과 확인 방법

| 영역 | 개발 기준 |
| --- | --- |
| 대시보드 / 프로젝트 | 접이식 사이드바, 프로젝트 추가·선택, 킥오프, 원본의 프로젝트 상세 탭, 목표·일정·체크리스트·보관과 복원 |
| 보관 | 전체 프로젝트의 산출물을 검색하고 원본 대화 열기, 완료한 업무 확인과 재개 |
| 업무 도구 | 주간업무보고, 업무 마감, 프로젝트별 다중 터미널, 뮤직 재생목록·재생 제어, 설정, 화면 잠금과 로그아웃 |
| 업무별 대화 | 자유 업무·리서치·브리핑·문서 작성, 독립된 대화 기록·역할·모델, 이전 대화 인계, 분기·되감기·승인·중단·재개 및 문서 내보내기 |
| 원본의 확장 기능 | 사용자가 선택하는 팀·의사결정·Git 작업 폴더와 변경 통합, 자원·저장 공간·알림, 모바일 접근, 외부 메일·일정·드라이브·음성 연결을 원본 동작별로 대조 |
| 디자인 | 직접 선택한 아이콘과 여러 회색 톤. 메뉴·본문·패널의 명도를 구분하고 진행·검토·완료에 절제된 상태색 사용 |
| 설치와 업데이트 | Apple Silicon 맥과 Windows x64. 각 운영체제에서 새 설치, 사용자별 인증과 데이터 분리, 새 버전 알림, 버튼으로 다운로드·검증·교체·새 창 기동과 실패 복구 확인 |

기능은 화면 진입, 입력, 실행, 저장된 결과, 재실행 복원을 구분해 기록합니다. 외부 계정이 필요한 기능은 모의 응답 및 실제 계정 검증을 구분합니다. 현재 버전에서 확인한 내용은 [기능 비교표](FEATURES.md)에 있습니다.

## 예상 일정

현재 맥에 설치한 0.2.0은 지금 사용할 수 있습니다. 첨부 화면의 주요 메뉴와 새 디자인을 먼저 사용할 수 있는 후보는 지금부터 약 1~2작업일, 원본의 확장 기능 대조와 양쪽 운영체제의 회귀 검증까지 포함한 전체 개발은 약 5~8작업일을 예상합니다. 두 기간은 누적 추정치이며 외부 서비스 승인과 Apple 인증서 발급·공증을 기다리는 시간은 별도입니다. Windows 설치 파일은 실제 설치·재시작 검증 후 GitHub 릴리스에 게시합니다.

## 기존 Maestro 제거 판단

설치된 Flowrium 0.2.0에는 자체 Electron 런타임, Apple Silicon용 Codex, 터미널 모듈이 들어 있습니다. 앱 실행 코드에서 Maestro 설치 경로 참조를 찾지 못했고 Maestro 런타임을 제외한 실행 경로로 내장 Codex의 동작을 확인했습니다.

Maestro 앱 제거와 Maestro의 데이터·개발 도구 정리는 다른 작업입니다. Maestro 설치본은 홈 폴더의 workspace/maestro/data/state에 자신의 상태를, .maestro에 설정과 실행 도구를 둘 수 있습니다. 개발·배포에 Maestro의 런타임이나 GitHub CLI를 사용했다면 독립 설치 여부를 확인합니다. Flowrium에서 실제 프로젝트를 열어 업무·산출물의 이전과 복원, 업데이트를 확인한 뒤 앱 번들을 제거할 수 있습니다. 기존 상태 폴더나 실행 도구까지 정리하려면 필요한 자료를 백업하고 개발·배포 도구를 독립 경로로 먼저 전환합니다.
