# Flowrium 개발 범위와 사용 시점

2026년 11월 13일 기준입니다. Flowrium은 각 사용자가 자기 ChatGPT 계정으로 로그인하고, 자신의 프로젝트 폴더에서 대화를 나누어 작업하는 데스크톱 앱입니다. 사용자가 정한 업무만 시작합니다. 이번 버전의 AI 연결은 Codex와 ChatGPT입니다. 별자리 화면은 제외합니다.

## 만들 기능과 확인 방법

| 영역 | 개발 기준 |
| --- | --- |
| 대시보드 / 프로젝트 | 접이식 사이드바, 프로젝트 추가·선택, 킥오프, 원본의 프로젝트 상세 탭, 목표·일정·체크리스트·보관과 복원 |
| 보관 | 전체 프로젝트의 산출물을 검색하고 원본 대화 열기, 완료한 업무 확인과 재개 |
| 업무 도구 | 주간업무보고, 업무 마감, 프로젝트별 다중 터미널, 뮤직 재생목록·재생 제어, 설정, 화면 잠금과 로그아웃 |
| 업무별 대화 | 자유 업무·리서치·브리핑·문서 작성, 독립된 대화 기록·역할·모델, 이전 대화 인계, 분기·되감기·승인·중단·재개 및 문서 내보내기 |
| 원본의 확장 기능 | 사용자가 선택하는 팀·의사결정·Git 작업 폴더와 변경 통합, 자원·저장 공간·알림, 모바일 접근, 외부 메일·일정·드라이브·음성 연결을 원본 동작별로 대조 |
| 디자인 | 직접 선택한 아이콘과 여러 회색 톤. 메뉴·본문·패널의 명도를 구분하고 진행·검토·완료에 절제된 상태색 사용 |
| 설치와 업데이트 | Apple Silicon 맥과 Windows x64. 각 운영체제에서 새 설치, 사용자별 인증과 데이터 분리, 새 버전 알림, 버튼으로 다운로드·검증·교체·새 창 기동과 실패 복구 확인 |

기능은 화면 진입, 입력, 실행, 저장된 결과, 재실행 복원을 구분해 기록합니다. 외부 계정이 필요한 기능은 모의 응답 및 실제 계정 검증을 구분합니다. 현재 버전에서 확인한 내용은 [기능 비교표](FEATURES.md)에 있습니다.

## 이번 배포 목표

최신 요청의 마감은 2026년 11월 13일 오전 8시(한국 시간)입니다. Claude와 별자리 화면을 제외하고 원본의 실제 업무 기능을 가능한 범위까지 구현하고 Mac Apple Silicon 및 Windows x64에서 검증한 설치 파일을 게시합니다. 외부 계정이 필요한 기능은 본인의 인증을 입력하는 선택형으로 제공하며, 실제 계정 승인과 모의 검증을 구분합니다.

정식 Apple Developer ID와 공증 정보는 현재 등록돼 있지 않습니다. 이번 Mac 패키지는 임시 서명 상태를 명시하고 첫 실행 시 운영체제의 보안 확인이 필요할 수 있음을 안내합니다. 자동 업데이트가 새 Mac 앱의 공증을 확인할 수 없으면 기존 앱을 보존하고 수동 설치로 안내합니다.

## 설치 파일 공개 기준

Mac과 Windows의 배포 파일, 설치 후 실행과 업데이트 검증 결과는 버전별 릴리스에 기록합니다. 최신 파일은 [다운로드 페이지](https://hyeondk.github.io/flowrium/)에서 확인할 수 있습니다. Apple 공증 여부와 Windows 코드 서명 상태도 해당 버전의 설명을 확인하세요.

## 기존 Maestro 제거 판단

설치된 Flowrium 0.3.0에는 자체 Electron 런타임, Apple Silicon용 Codex, 터미널 모듈과 Node.js / npm / GitHub CLI / Cloudflare 터널 실행기가 들어 있습니다. Maestro 런타임을 제외한 실행 경로에서 내장 도구와 Codex를 확인했습니다. 실제 DMG에서 앱을 복사해 설치하고 버전과 기존 ChatGPT 연결을 확인한 뒤 정상 종료했습니다. 설치된 Maestro 앱과 사용자 자료는 삭제하지 않았습니다.

Maestro 앱 제거와 Maestro의 데이터·개발 도구 정리는 다른 작업입니다. Maestro 설치본은 홈 폴더의 workspace/maestro/data/state에 자신의 상태를, .maestro에 설정과 실행 도구를 둘 수 있습니다. 개발·배포에 Maestro의 런타임이나 GitHub CLI를 사용했다면 독립 설치 여부를 확인합니다. Flowrium에서 실제 프로젝트를 열어 업무·산출물의 이전과 복원, 업데이트를 확인한 뒤 앱 번들을 제거할 수 있습니다. 기존 상태 폴더나 실행 도구까지 정리하려면 필요한 자료를 백업하고 개발·배포 도구를 독립 경로로 먼저 전환합니다.
