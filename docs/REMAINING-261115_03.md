휴지통 정리는 실제 참조와 현재 사본 재사용을 확인하며, 확인 뒤 기록이나 참조가 바뀌면 새 확인이 필요합니다. 계정 / 잠금 / 실행 / 대기 상태와 저장 위치를 검사하고, 일부 파일을 처리하지 못하면 삭제한 기록과 남은 기록을 나누어 표시합니다. 원문과 첨부는 참조 수와 관계없이 보존합니다. 자세한 범위와 한도는 [삭제와 복원](DELETION.md)을 확인하세요.
