## 대화 연결과 삭제의 범위

- 같은 Codex 대화는 원래 식별자로 이어 쓰며 한 앱에서만 작성합니다. 원래 앱 전용 도구와 연결 대화의 분기 / 되감기 / 압축에는 제한이 있습니다.
- 기본 삭제는 Flowrium 항목을 계정별 휴지통으로 옮깁니다. 대화 복원과 프로젝트 연결 복원을 지원하며 프로젝트의 실제 작업 폴더는 보존합니다. 원래 앱의 프로젝트나 ChatGPT 웹 대화를 함께 지우지 않습니다.
- 현재 기기와 계정으로 연결한 원래 Codex 대화는 별도 선택으로 보관하거나 영구 삭제하는 확인 화면을 추가했습니다. 공식 앱 서버 인터페이스의 지원과 소유권 / 실행 상태를 확인하고 원본 및 자동 생성 하위 대화의 영향 목록을 표시합니다. 영구 삭제는 추가 확인과 정확한 대상 이름이 필요합니다. 사본은 원본에 삭제를 전파하지 않습니다.
- 원본 영구 삭제는 되돌릴 수 없으며 휴지통 복원은 Flowrium의 독립 사본으로 수행합니다. 보관 취소는 이번 처리에서 보관된 것으로 확인한 원본에만 시도합니다. 외부 처리 실패와 부분 성공은 휴지통 기록에 남기고 실제 결과를 안내합니다.
- **두 앱 사이의 자동 양방향 삭제 동기화는 제공하지 않습니다.** 원래 대화에서 사라진 메시지를 Flowrium에서 자동 영구 삭제하거나, 로컬 원본 DB를 직접 변경하거나, 조회 목록에 없다는 이유로 삭제하지 않습니다. 실제 사용자 원본의 보관 / 영구 삭제는 이번 검증에 실행하지 않았습니다. 자세한 범위는 [삭제와 복원](DELETION.md)을 확인합니다.
- 통합 채팅은 제공된 최근 현황을 읽습니다. 프로젝트 100개 / 프로젝트당 최근 대화 15개 / 대화당 최근 메시지 4개 한도가 있으며, 원본의 모든 파일과 대화를 무제한 읽지 않습니다.
- ChatGPT 웹 대화는 주소 연결과 본문 복사입니다. 웹 전체 대화 목록과 자동 동기화하는 기능은 없습니다.
