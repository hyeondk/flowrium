## 수정과 재현 확인

- 표가 평문으로 보이던 문제를 수정했습니다. 표 / 체크 목록 / 취소선 / 한국어 각주 / 안전하지 않은 링크 차단을 확인했고 320~1440px에서 넓은 표의 가로 스크롤을 표 안에 한정했습니다.
- 외부 폴더 선택 오류가 늦은 권한 조회 성공으로 지워지던 경합을 수정했습니다. 오류 발생 뒤 조회가 완료되는 순서를 강제로 재현해 오류 보존과 이후 정상 저장을 확인했습니다.

- 서로 다른 런타임의 한글 조합 차이로 같은 프로젝트 폴더를 다른 경로로 오인하던 오류를 수정했습니다. 실제 경로나 파일명을 바꾸지 않으며 다른 폴더와 심볼릭 링크의 경계 검사를 유지했습니다. 같은 한글 프로젝트의 새 전송까지 다시 확인했습니다.
- 일정 화면의 너비가 수축해 새 일정 버튼을 누를 수 없던 조건을 재현했습니다. 전용 화면의 폭과 내부 스크롤 경계를 수정하고 같은 등록 / 선택 조건과 안정화 뒤 위치를 재검사했습니다.
- 실행 코드의 중복 선언으로 시작하지 못하는 오류를 수정하고, 최종 빌드 첫 단계에 Electron 구문 검사를 추가했습니다.
- 검사 자체의 초기 문서 로드 / 비동기 폴더 열기 / 모달 분리 시점을 실제 완료 경계로 바꿨습니다. 새 메뉴와 조밀한 화면 규격도 검사에 반영했으며 강제 클릭으로 가림을 우회하지 않았습니다.

## 실제 Mac 교체와 로컬 자료

기존 앱을 정상 종료하고 사용자 설정과 프로젝트 기록을 백업한 뒤 터미널 설치기로 교체했습니다. 설치 버전 / 파란 아이콘 파일 / 서명 무결성 / 기존 계정과 사용량 / 이관한 대화 본문 / 오른쪽 고정과 대시보드 / 기본 접힌 작업 기록을 확인하고 정상 종료했습니다. 개인 대화와 첨부는 공개 파일에 포함하지 않습니다.

Dots는 실제 공식 웹의 익명 로그인 화면까지 열렸습니다. 기존 ChatGPT 계정을 사용하는 별도 웹 세션이며, Codex OAuth를 공식 웹 세션으로 자동 교환하는 연결은 구현하지 않았습니다. 실제 로그인 후 대화는 미검증입니다.

## Mac 앱 목록과 설치 백업

이전 설치 백업의 내부 Helper가 독립 앱으로 등록된 사례를 재현했습니다. 설치기의 백업을 숨김 `.flowrium-backups.noindex`에 보관하고, 확인한 이전 백업도 원본을 보존해 옮깁니다. 해당 백업과 Helper만 등록 해제하고 현재 Flowrium만 등록하며, 전체 시스템 앱 목록을 초기화하지 않습니다. 실제 기기에서 Helper 등록 0개와 응용 프로그램 목록의 Flowrium 한 개를 확인했습니다. 배포용 설치기는 격리한 실제 Mac 설치와 실패 복원, 링크 거절, 기존 백업 이관, 다른 제품 보존을 검사합니다.
