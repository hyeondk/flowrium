Flowrium으로 돌아가기

개인정보와 연결 자료 안내

Flowrium은 사용자가 선택한 프로젝트와 AI 대화, 연결 계정의 자료를 이용하는 데스크톱 앱입니다.

기기에 보관하는 자료

프로젝트와 대화, 첨부, 기억, 초안과 설정은 앱 자료 폴더 및 사용자가 선택한 프로젝트의 자료 폴더에 저장됩니다. 대화 파일 전체가 자동으로 암호화되는 구조는 아닙니다. 계정 토큰 등 지원되는 비밀값은 운영체제의 보안 저장소로 보호합니다. 사용자가 고른 파일 동기화 서비스나 백업 도구의 전송은 해당 설정을 따릅니다.

AI와 외부 서비스

사용자가 AI 업무를 요청하면 요청 내용과 필요한 프로젝트 문맥이 연결한 OpenAI 서비스에 전달될 수 있습니다. 각 사용자는 자신의 계정으로 연결하며, 이용 가능 모델과 데이터 처리는 해당 서비스와 계정 설정을 따릅니다. Dots는 별도 세션의 ChatGPT 공식 웹 화면으로 연결되며 Flowrium 대화와 자동으로 합쳐지지 않습니다.

Google 연결

Google 계정 연결과 권한 동의는 사용자 본인의 브라우저에서 진행합니다. 연결한 캘린더와 메일, 드라이브의 자료는 앱의 조회·일정 관리·자료 가져오기·사용자가 요청한 AI 업무에 이용합니다. 일정 변경이나 메일 발송은 앱에서 내용을 검토하고 실행하는 경로를 거칩니다. Google 로그인과 공개 권한 검증은 배포자의 별도 준비가 필요합니다.

계정과 자료 관리

설정에서 Google 연결을 해제할 수 있고, Google 계정의 연결 앱 관리에서 접근 권한을 철회할 수 있습니다. 이미 프로젝트에 저장한 대화와 파일은 별도로 남습니다. Flowrium의 휴지통은 복원을 위한 자료를 보존합니다. 연결한 원래 Codex 대화의 영구 삭제는 별도 확인을 거치며, 일반 프로젝트 삭제는 원래 작업 폴더를 지우지 않습니다. 백업 파일은 앱 항목과 별도로 관리합니다.

공개 배포와 연락

공개 설치 파일과 소스에는 배포자의 개인 대화와 로그인 토큰을 포함하지 않습니다. 업데이트 확인에는 GitHub가 이용되며 외부 서비스 접속에는 각 서비스의 네트워크 처리가 적용됩니다. 문의는 Flowrium 저장소로 남길 수 있습니다. 공개 문의에 비밀번호나 계정 토큰, 비공개 대화 원문을 올리지 마세요.
