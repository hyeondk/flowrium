## 기능과 데이터

- 로컬 빌드와 단위 검사 82개를 통과했습니다. 실제 Electron 창에서 프로젝트 생성과 재연결 / 아홉 탭 / 목표 / 보관과 재개 / 독립 업무 대화 / 팀 배정과 결정 / Git 작업 폴더의 변경 검토와 병합 / 메모와 비서 / 잠금 / 초안 복원 / 문서 저장을 확인했습니다.
- Windows 검증 작업은 13분 35초에 성공했습니다. 단위 검사는 82개 중 81개 통과 / 1개 건너뜀 / 실패 0개입니다. 건너뛴 검사는 Windows의 심볼릭 링크 생성 권한이 필요한 외부 기록 차단 항목이며 맥에서는 실행했습니다. Windows 가상 터미널 별도 검사 2개도 모두 통과했습니다.
- Codex 0.167.2가 보내는 추가 질문은 실제 번들 서버와 로컬 모의 모델을 연결해 답변이 다음 모델 요청으로 전달되는 데까지 확인했습니다. 비밀 질문과 잠금 / 계정 변경에 대한 처리는 별도로 검사했습니다.
- 마크다운 / HTML / PDF / PPTX를 실제 앱에서 만들고 본문과 구조를 다시 읽었습니다. 맥에서는 오피스 변환기로 발표자료를 다시 열어 두 페이지인지 확인했습니다.
- 모바일 크기의 실제 브라우저에서 대화 생성 / 요청 / 중단 / 승인 / 일반 질문 답변 / 문서 조회 / 인증과 잠금 / 대화 기록 나눠 읽기를 검사했습니다.
- 기존 ChatGPT 계정으로 시험 프로젝트의 응답을 한 번 생성해 저장했습니다. 실제 YouTube 공식 예제 영상은 제목과 재생 위치를 확인하고 13초 이상 재생했습니다.

일반 화면 검사의 AI 응답과 외부 서비스 응답은 격리된 모의 연결을 사용합니다. 실제 개인 계정 검증과 구분합니다.

## 업데이트와 서명

- Windows에서 실제 공개된 0.2.0을 내려받아 설치한 뒤 앱의 업데이트 배너를 클릭했습니다. 새 0.3.0 설치 파일 다운로드 / NSIS 교체 / 새 프로세스와 창 기동 / 버전 확인 / 기존 프로젝트와 메시지 및 미전송 초안 복원을 통과했습니다. 새 설치 파일을 제공하는 HTTP 응답만 시험 서버로 연결하고 실제 앱의 화면 / IPC / 업데이트 처리 / 설치 도우미를 사용했습니다.
- 맥에서 실제 업데이트 버튼으로 미공증 새 ZIP을 받으면 앱 교체를 거절하고 현재 앱을 유지하는지, 수동 설치 버튼으로 다운로드 페이지를 여는지 확인했습니다. 이전 공개 맥 설치본에서 새 앱을 수동 교체한 뒤 기록과 미전송 초안이 보존되는 것도 검사했습니다.
- 이번 맥 설치본에는 Apple Developer ID와 공증이 없고 Windows 설치본에는 배포자 코드 서명이 없습니다. 다른 컴퓨터에서 처음 설치할 때 운영체제의 보안 안내가 나타날 수 있습니다.
- 맥의 자동 교체는 새 앱의 Developer ID 서명과 Apple 공증 확인을 전제로 합니다. 이번 미공증 버전은 DMG 수동 설치를 사용합니다.

## 실제 환경 검증이 남은 항목

Google 계정의 실제 동의 / 유료 OpenAI 음성 인식 / 실제 마이크 장치 / 개인 휴대전화의 외부 회선 접속은 검증하지 않았습니다. 음성의 권한 / 녹음 중단 / 화면 전환과 늦은 응답 처리는 모의 장치로 검사했습니다. 실제 Cloudflare 터널 등록과 HTTPS 응답은 확인했지만 시험 맥의 새 도메인 DNS 해석 문제로 진단용 DNS 조회를 사용했습니다.

원본의 카카오 연동 / 메일 회신 자동화 / 자동 가사 수집 / 일부 카드 일괄 처리와 그래프는 포함하지 않습니다. 제외하거나 검증하지 않은 원본 기능은 [경로별 비교표](FEATURES.md)에 구분했습니다. Claude와 별자리 화면은 이번 개발 범위에서 제외했습니다.

## 작업 종료 정리

맥에 설치한 새 Flowrium을 정상 종료하고 작업에서 실행한 Flowrium / 시험용 Electron 프로세스가 0개인 것을 확인했습니다. 사용자 자료는 보존했습니다. 최종 설치 파일과 이전 설치본, 실행 필수 도구는 보존하고 종료된 시험 스크립트와 중간 로그는 정리했습니다.
