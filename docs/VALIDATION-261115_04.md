# Flowrium 261115_04 검증 기록

대상은 Apple Silicon 맥과 64비트 윈도우입니다.

| 확인한 동작 | 재현 조건과 결과 |
| --- | --- |
| 입력창에서 다음 작업 추천 | 초기화나 추론 중 분석이 종료되면 제한 시간과 취소 사유가 같은 연결 종료 메시지로 표시되던 문제를 재현했습니다. 입력창 미리보기, 탭으로 선택, 직접 수정, 보내기를 검사했습니다. 실제 로그인 계정으로 합성 대화를 사용해 모델의 추천 응답도 확인했습니다. |
| 프로젝트 홈 배치 | 맥에서 같은 화면의 수정 전후를 실측했습니다. 제목 행의 위쪽 여백은 41~45픽셀에서 17픽셀로, 빈 바로가기 카드는 높이 216픽셀에서 103픽셀로 줄었습니다. |
| 대화 도구 | 창 너비 320~1440픽셀에서 답변의 복사 / 읽어주기 / 좋아요 버튼 간격은 2픽셀이고 마지막 버튼과 본문 오른쪽 정렬선의 차이는 0픽셀이었습니다. 재생과 중지, 좋아요 선택도 확인했습니다. |
| 데스크톱 대화 | 두 Codex 앱 서버가 같은 대화에 번갈아 기록하고 Flowrium이 새 답변을 받아오는 시험과, 실제 로그인 계정의 합성 대화에서 이전 문맥을 다시 확인하는 시험을 수행했습니다. 한쪽에서 진행 중인 요청은 끝난 뒤 이어갑니다. |
| 삭제 재시도 | 합성 대화로 원본이 이미 없어진 경우, 목록에 아직 있는 경우, 프로젝트에 두 상태가 섞인 경우와 복원 중 재요청을 검사했습니다. 완료된 동일 삭제 요청에는 기존 결과를 반환합니다. |

## 사용 범위

자동 갱신 대상은 같은 기기와 계정의 연결된 Codex 작업 대화입니다. 일반 ChatGPT 웹 기록에는 대화가 자동 등록되지 않습니다. 열린 공식 앱의 사이드바를 강제로 새로 그리거나 공식 앱의 삭제 버튼 동작을 변경하는 기능은 제공하지 않습니다. [공식 데스크톱 대화 링크](https://learn.chatgpt.com/docs/reference/commands#deep-links)

맥의 공개 설치본은 임시 서명을 사용합니다. Apple 공증과 공증된 앱의 자동 교체는 별도 조건입니다.
