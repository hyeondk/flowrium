## Apple Silicon 맥

- 단위 검사 345개가 통과했습니다. 기능 검사 54개 중 53개가 첫 실행에서 통과했습니다. 외부 저장소 검사에서 같은 문구가 경고와 상태 안내 양쪽에 표시되는 상황을 재현하고, 권한 안내 행을 지정해 나머지 한 검사도 같은 제품에서 통과했습니다.
- 최종 맥 패키지로 내장 터미널, 일반 실행과 종료 두 차례, 업데이트 버튼의 수동 설치 안내, 미공증 패키지 교체 거부와 기존 앱 보존을 확인했습니다. 디스크 이미지와 압축 파일 안의 앱 항목 3,214개를 대조했습니다.
- 실제 응용 프로그램 폴더에 릴리스 압축 파일로 설치했습니다. 실행 파일, 앱 코드, 아이콘, 앱 정보가 릴리스와 일치했습니다. 설치본을 일반 실행해 기존 프로젝트 홈과 우측 고정 대화, 대화 자동 동기화, 추천과 메시지 도구를 확인한 뒤 정상 종료했습니다.
- 실제 로그인 계정으로 시험용 대화에서 모델의 후속 추천을 받았습니다. 같은 대화를 양쪽에서 번갈아 이어 쓴 뒤 공식 데스크톱 대화 읽기 기능으로 세 차례의 기록과 마지막 응답을 확인했습니다. 사용자의 개인 대화 본문을 검증 기록에 싣지 않았습니다.

## 배포 파일에 포함된 자료

태그 소스 `b695511`의 압축 파일 476개를 저장소와 대조했습니다. 맥 패키지를 만든 `28caeb2`와의 차이는 외부 저장소 자동 검사의 선택자 한 줄입니다. 제품 소스와 패키지 입력은 두 커밋에서 같습니다.

개인 프로젝트 경로, 대화 식별자, 본문 일부에서 뽑은 표식 21개로 소스와 양쪽 최종 설치본을 검사했습니다. 검사 대상에서 일치한 표식과 금지된 경로는 각각 0개였습니다. 맥의 앱 코드 묶음 1,427개 / 리소스 2,305개 및 윈도우의 앱 코드 묶음 1,437개 / 리소스 2,321개를 대상으로 했습니다. 대형 외부 공급자 바이너리의 내용은 맥 11개, 윈도우 17개가 표식 비교에서 제외됐습니다.

2026년 11월 15일 16시 7분(한국 시간)에 양쪽 설치본을 공개했습니다. 공개 파일 9개의 크기와 SHA-256이 로컬 정본과 일치했고, 인증 없이 다운로드 주소 9개 모두 HTTP 200을 반환했습니다. 이 단계는 GitHub 서버 확인값과 익명 주소를 대조하는 방식으로 진행했습니다. [공개 릴리스](https://github.com/hyeondk/flowrium/releases/tag/261115_04) / [파일별 검증 결과](validation/release-261115_04.json)

## 사용 범위

자동 갱신 대상은 같은 기기와 계정의 연결된 Codex 작업 대화입니다. 일반 ChatGPT 웹 기록에는 대화가 자동 등록되지 않습니다. 열린 공식 앱의 사이드바를 강제로 새로 그리거나 공식 앱의 삭제 버튼 동작을 변경하는 기능은 제공하지 않습니다. [공식 데스크톱 대화 링크](https://learn.chatgpt.com/docs/reference/commands#deep-links)

맥의 공개 설치본은 임시 서명을 사용합니다. Apple 공증과 공증된 앱의 자동 교체는 별도 조건입니다.
