# Flowrium 261115_09

- 휴대폰의 연한 파랑 배경과 블루그레이 색상을 유지하면서 대시보드, 프로젝트 목록, 대화, 설정의 여백과 정렬을 다듬었습니다. 대시보드 첫 카드에서 연결된 프로젝트 수와 작업중 / 대기 / 결정 상태를 확인할 수 있습니다.
- 하단 바를 좌우로 끌면 선택 표시가 손가락을 따라가고, 놓으면 해당 탭이 열립니다. 트랙패드로도 이동할 수 있고, 글자를 크게 표시해 메뉴가 넘칠 때는 바 자체를 좌우로 스크롤할 수 있습니다.
- 휴대폰 **설정 → 앱 버전 및 업데이트**에서 현재 버전을 확인하고 호환되는 새 모바일 화면을 적용할 수 있습니다. 개인 프로젝트와 대화는 연결한 컴퓨터에 보관됩니다.
