# Flowrium 261115_04

- **대화 추천**을 입력창에서 바로 확인합니다. 마지막 답변이 끝난 뒤 빈 입력창을 선택하면 모델이 다음 작업을 제안합니다. `Tab` 또는 추천 버튼으로 초안에 넣고, 다른 후보를 보거나 `Esc`로 닫을 수 있습니다. 연결이 끊기면 입력창에서 다시 요청할 수 있습니다.
- **같은 기기의 Codex 대화**를 두 앱에서 순서대로 이어 씁니다. 연결한 기존 대화와 Flowrium에서 실행해 연결된 대화의 새 기록을 확인합니다. 열린 대화는 창에 돌아올 때와 5초 간격으로 갱신하며 상대 앱의 작업이 끝난 뒤 반영합니다. ChatGPT 웹 일반 대화로 옮길 때는 **ChatGPT로 이어가기**를 사용해 직접 붙여 넣습니다. [대화 연결 방법](https://github.com/hyeondk/flowrium/blob/main/docs/CODEX-CHAT-LINK.md)
- **프로젝트 홈**에서 업무 건수와 다음 업무가 먼저 보입니다. 제목과 버튼 높이를 맞추고, 빈 바로가기 카드의 여백을 줄였습니다. 답변의 복사 / 읽어주기 / 좋아요 버튼은 대화 본문 오른쪽 끝에 모았습니다. [화면 예시](https://github.com/hyeondk/flowrium/blob/main/docs/project-chat-261115_04.png)
- **삭제 재시도** 시 같은 계정의 휴지통 기록을 확인합니다. 이미 옮긴 항목은 **목록 갱신**으로 처리할 수 있습니다. 원래 Codex 대화가 일반 목록과 보관 목록에 모두 없으면 이 상태를 표시합니다. Flowrium의 프로젝트 연결을 해제해도 작업 폴더는 유지됩니다. [삭제와 복원](https://github.com/hyeondk/flowrium/blob/main/docs/DELETION.md)

설치 대상은 Apple Silicon 맥과 64비트 윈도우입니다. 맥 설치 시 Apple 공증 상태에 따라 첫 실행 확인이 필요할 수 있습니다. 공개 설치 파일과 확인값은 다운로드 페이지와 릴리스에서 확인할 수 있습니다. [다운로드](https://hyeondk.github.io/flowrium/) / [터미널 설치 안내](https://github.com/hyeondk/flowrium/blob/main/docs/TERMINAL-INSTALL.md)
