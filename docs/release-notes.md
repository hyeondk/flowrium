Flowrium 0.6.0은 전체 자료 이관 / 로컬 음성 서버 관리 / 자동 포트표와 파란색 화면을 추가합니다.

- 프로젝트와 대화 / 첨부 / 도구 기록 / 기억 / 설정 / 초안을 새 위치로 옮기고 원문과 적용 전 백업을 보관합니다. 실패 시 변경을 되돌리고, 강제 종료는 다음 기동에서 복구합니다. 인증과 암호는 제외하며 이관 후 다시 시작합니다.
- 준비한 음성 서버의 실행 명령을 검토해 시작 / 중지 / 재시작하고 상태와 로그를 확인합니다. 앱이 관리하지 않는 외부 서버와 재사용된 프로세스 번호는 보존합니다.
- 프로젝트 번호로 서비스 포트를 자동 배정하고 실제 수신 여부 / 충돌 / 예약 / 사용자 지정과 주소 복사를 제공합니다.
- 아주 연한 파란 배경 / 청회색과 남색 강조 / 둥근 버튼 / 왼쪽 정렬 메뉴 / 오른쪽 행동 그룹 / 스위치를 적용했습니다. 인증 후 위로 올라가는 잠금 해제와 좋아요의 탄성 반응을 추가했습니다.
- 주간업무보고 / 업무 마감 / 대화 관리를 중앙 팝업에서 엽니다. 보고와 마감에서도 계정이 제공한 모델과 추론 강도를 선택합니다.

각 사용자는 본인 ChatGPT 계정으로 로그인합니다. 기존 앱의 전체 동작 동일성이나 모든 외부 서비스의 실제 계정 검증을 보증하지 않습니다. 이관할 개인 자료는 보존한 원본과 결과를 대조한 뒤 전환하세요.

Mac ARM64 / Windows x64를 제공합니다. Mac은 Developer ID 서명과 Apple 공증이 없는 버전이며 처음 실행할 때 운영체제가 제한할 수 있습니다. 터미널 설치기는 검증과 백업을 제공하며 보안 정책을 해제하지 않습니다. 미공증 Mac 앱의 내부 자동 교체는 허용하지 않고 수동 설치를 안내합니다.
