## 기능별 프로젝트 대화

리서치 / 브리핑 / 문서 작성 / 주간업무보고 / 업무 마감 / 자유 업무를 별도 대화로 만들고, 각 대화에서 역할과 체크리스트, 진행 상태를 관리할 수 있습니다. 답변을 프로젝트의 산출물로 저장하고, 문서와 저장소의 변경 사항을 다시 확인할 수 있습니다. 앱과 다운로드 페이지에 새 Flowrium 아이콘을 적용했습니다.

- 프로젝트의 담당자, 목표, 기한, 체크리스트와 보관 상태를 관리합니다. 팀의 공동 요청을 역할별 독립 대화에서 동시에 실행할 수 있습니다.
- 대화 관리에서 분기와 되감기, 문맥 압축을 요청할 수 있습니다. 대기 중인 실행 요청은 통합 승인함에서 확인합니다.
- 업무 결과를 마크다운 / HTML / PDF / PPTX로 저장합니다. 파일 선택과 끌어놓기로 기존 문서도 산출물에 추가할 수 있습니다.
- 형상관리에서 선택 파일의 차이와 커밋, 브랜치 푸시, 변경 요청 생성을 지원합니다. 변경 요청 병합 시 조회한 커밋이 현재 원격 커밋과 일치하는지 확인합니다.
- 작업 현황은 실행 중인 업무와 요청, CPU / 메모리 상태를 보여 줍니다. 업무 보드, 새 대화, 기록, 설정에는 키보드 단축키가 있습니다.

- 각 대화에 모델 / 추론 강도 / 이어갈 ChatGPT 웹 대화 주소를 따로 저장할 수 있습니다.
- 프로젝트 안에 여러 터미널을 열고 작업 대화와 터미널 사이를 오갈 수 있습니다.

## 설치와 대화 기록

- Windows 64비트에서는 `win-x64.exe`로 끝나는 설치 파일을 실행합니다. 이 배포의 Windows 설치 파일에는 배포자 코드 서명이 없습니다.
- Apple Silicon Mac은 Developer ID 서명과 Apple 공증을 기다리고 있습니다. 확인을 마친 설치 파일을 같은 다운로드 페이지에서 제공할 예정입니다.
- 0.2.0 이상에서는 새 공개 버전 알림의 **업데이트 후 재시작**을 누르면 같은 운영체제용 파일을 받아 확인한 뒤 교체합니다.
- 0.1.x에서는 새 설치 파일을 한 번 직접 받으세요. 앱을 교체해도 프로젝트의 `.flowrium/` 폴더는 보존됩니다.
- 이 컴퓨터에서 연결한 폴더와 일치하는 기존 Codex 대화의 사용자 메시지와 응답을 가져올 수 있습니다. 일반 ChatGPT 웹에서는 전달할 내용을 복사해 붙여 넣습니다.
- 설치 파일의 SHA-256 확인값은 같은 릴리스에 첨부된 `SHA256SUMS.txt`에 있습니다.
