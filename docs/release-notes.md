# Flowrium 261114_01

설정 화면의 배치와 버튼 체계를 정리하고 기존 Codex 프로젝트 대화를 같은 문맥으로 이어 쓰는 연결 기능을 추가했습니다.

## 변경

- 설정을 일반 / 보안 / 대화와 자료 / 외부 자료 / 휴대폰 / 음성 / 계정과 모델 / 화면으로 나누어 탐색합니다. 기본 20px / 좁은 화면 16px 내부 여백, 문구 줄바꿈, 제어 요소 높이와 배치를 정리했습니다.
- 주요 실행은 강조하고 보조 행동은 투명한 버튼으로 묶습니다. 파란색과 회색 팔레트 / 나눔스퀘어라운드 / 왼쪽 정렬 메뉴 / 중앙 팝업 / 기존 움직임을 유지합니다.
- 프로젝트 대화 연결은 기본적으로 원래 `threadId`를 유지합니다. 본문과 도구 기록, 첨부 참조와 확인 가능한 지원 로컬 이미지를 보관하고 원문을 로컬에 저장합니다. 중복을 방지하며 수동 새로고침과 20초 간격 / 창에 돌아올 때의 갱신을 제공합니다.
- 원래 대화와 별개로 작업하는 독립 사본도 선택할 수 있습니다. 같은 대화는 한 앱에서만 작업하며 Flowrium은 실행을 마친 뒤 전용 연결을 닫아 반환합니다.
- 임시 이미지가 사라졌으면 공식 대화 기록과 명시된 이전 기록에서 본문 / 첨부 경로 / 개수 / 순서가 일치하는 사본을 복구합니다. 여러 후보가 다르면 복구하지 않고, 다시 연결할 때 부족한 첨부를 재확인합니다. 기록 사본은 원래 파일과 해상도나 바이트가 다를 수 있습니다.
- 공개 버전과 설치 파일 이름은 `YYMMDD_순번` 형식을 사용합니다. [버전 규칙](https://github.com/hyeondk/flowrium/blob/main/docs/VERSIONING.md)

## 확인한 범위와 남은 검증

Mac의 격리된 앱에서 업무 화면 / 움직임 / 프로젝트와 확장 기능 / 데스크톱 도구 / 다운로드 페이지 / 설정 배치 회귀를 확인했습니다. 설정은 320 / 390 / 800 / 1440px 폭에서 가로 넘침 없이 검사했습니다. 실제 모델을 사용한 양방향 세 차례 왕복과 Codex 앱의 대화 조회 도구를 통한 결과 조회도 확인했습니다. 이미 열려 있는 원래 앱 화면의 즉시 갱신은 확인하지 않았습니다.

운영체제별 설치와 업데이트 / 공개 파일 대조의 최종 결과는 [261114_01 검증 기록](https://github.com/hyeondk/flowrium/blob/main/docs/VALIDATION-261114_01.md)에 구분해 기록합니다. 개인 대화와 원문은 각 기기에 저장하며 공개 배포 파일에 포함하지 않습니다.

## 설치와 사용 조건

대상은 Mac ARM64 / Windows x64입니다. **0.6.0 이하에서는 날짜 태그를 인식하지 못하므로 새 날짜 버전은 한 번 수동으로 설치해야 합니다.** 이후 날짜 버전은 날짜와 순번으로 업데이트를 확인합니다. 미공증 Mac은 수동 설치를 안내하며 터미널 설치도 보안 정책을 해제하거나 경고 없는 실행을 보장하지 않습니다.

연결 대화의 동시 작성 / 원래 앱 전용 도구 / 분기 / 되감기 / 압축에는 제한이 있습니다. 계정과 기기를 확인하고 개인 원문과 대화는 공개 패키지에서 제외합니다. 실제 필요한 자료와 기능을 확인한 뒤 기존 앱의 삭제를 결정하세요.
