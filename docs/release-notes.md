# Flowrium 261116_01

- 원본에 연결된 프로젝트 대화의 ID가 비어 있어 전송이 실패하는 문제를 수정했습니다. Flowrium에 포함된 Codex가 작업을 실행하므로 별도 ChatGPT 앱을 켜 둘 필요가 없습니다.
- 대화 자동 갱신과 보내기가 겹치면 갱신을 마친 뒤 입력한 요청을 이어서 전송합니다.
- 채팅 본문의 줄 간격과 문단 여백을 조정하고 사용자 발언은 오른쪽, AI 답변은 왼쪽에 배치했습니다. 작업 과정은 요청 단위로 펼쳐 보고, 여러 장의 사진은 가로로 넘겨 볼 수 있습니다.
- 실행 중 추가 지시, 입력 중 마크다운 미리보기, 계정에 제공된 새 모델 알림을 추가했습니다. 채팅 하단에는 AI의 접근 범위와 구현 모드 전환을 표시합니다.
- 프로젝트를 길게 눌러 좌우 패널의 순서를 함께 정렬하고, 연결된 Codex 프로젝트와 채팅의 표시 이름을 동기화할 수 있습니다. 보관한 프로젝트를 재개할 때 진행 단계도 복원합니다.
- 대시보드의 업무 도구를 용도별로 묶고 프로젝트 카드에 구분을 표시했습니다. 날짜 선택과 체크박스에 화면 색상을 적용했고, 하단 안내는 연파랑, 경고는 연한 빨강으로 표시합니다. 재생목록을 삭제하면 해당 곡과 재생 대기 목록도 함께 닫힙니다.
- 맥 데스크톱은 Apple 미공증 버전입니다. 출처와 검증값을 확인한 뒤 공식 설치 파일로 교체할 수 있습니다.
