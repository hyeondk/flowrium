## 프로젝트 대시보드와 전용 업무 대화

- 대시보드에서 프로젝트를 만들고 목표, 담당자, 기한을 정하거나 기존 폴더를 연결합니다. 프로젝트 상세의 아홉 탭에서 주간 / 월간 목표, 팀, 규칙, 디자인 시안, 회의록, 파일, 저장소를 엽니다.
- 리서치 / 브리핑 / 문서 작성 / 주간업무보고 / 업무 마감 / 자유 업무를 별도 대화로 실행합니다. 여러 프로젝트를 선택한 주간 보고는 기간별 완료 업무와 Git 커밋을 집계합니다. 업무 마감은 선택한 프로젝트마다 인계 대화를 만듭니다.
- 대시보드에서 최근 업무와 실행 중인 작업, 승인을 관리합니다. 전체 산출물과 완료 목록에서 원본 대화를 열거나 보관한 프로젝트와 마친 업무를 재개합니다. 답변을 마크다운 / HTML / PDF / PPTX로 저장할 수 있습니다.
- 팀에서 역할별 작업을 계획하고 배정하거나 공동 요청을 동시에 실행합니다. 각 대화의 모델 / 추론 강도 / 연결한 ChatGPT 웹 대화를 따로 설정할 수 있습니다.
- 선택한 파일의 차이와 커밋, GitHub 변경 요청과 병합, 프로젝트 단위 터미널과 서비스 상태를 확인합니다.
- 사이드바에서 뮤직, 잠금과 계정 로그아웃을 엽니다. 데스크톱에서 모바일 연결을 켜면 브라우저로 대화와 프로젝트 자료를 확인하고 요청 / 중단 / 승인을 수행할 수 있습니다.

## 설치와 대화 기록

- Windows 64비트에서는 `win-x64.exe`로 끝나는 설치 파일을 실행합니다. 이 배포의 Windows 설치 파일에는 배포자 코드 서명이 없습니다.
- Apple Silicon Mac용 디스크 이미지와 업데이트 ZIP을 제공합니다. 이번 미공증 빌드는 Apple에서 확인한 개발자로 표시되지 않습니다. 첫 실행이 제한되는 경우 [맥 설치와 첫 실행 안내](https://github.com/hyeondk/flowrium#local-mac)를 확인하세요.
- Windows에서는 **업데이트 후 재시작**으로 새 공개 버전을 다운로드하고 확인한 뒤 교체합니다. Mac의 앱 내 교체는 새 파일의 Developer ID 서명과 Apple 공증을 확인해야 진행됩니다. 미공증 파일을 받으면 현재 앱을 유지하며 0.3.0의 **수동 설치 파일 받기**로 DMG를 열 수 있습니다.
- 0.1.x에서는 새 설치 파일을 한 번 직접 받으세요. 앱을 교체해도 프로젝트의 `.flowrium/` 폴더는 보존됩니다.
- 이 컴퓨터에서 연결한 폴더와 일치하는 기존 Codex 대화의 사용자 메시지와 응답을 가져올 수 있습니다. 일반 ChatGPT 웹에서는 전달할 내용을 복사해 붙여 넣습니다.
- 설치 파일의 SHA-256 확인값은 같은 릴리스에 첨부된 `SHA256SUMS.txt`에 있습니다.
