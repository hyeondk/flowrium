## Flowrium 0.4.0

- 창과 소개 페이지의 제목을 Flowrium으로 통일했습니다. 차분한 회색 계열 대시보드에 오늘의 할 일 / 목표와 기한 / 결정 대기 / 실제 업무 그래프 / AI 오늘 계획을 추가했습니다.
- 채팅 이미지·파일·캡처 첨부, 실행 중 추가 지시 대기열, 실제 내부 대화의 요청별 분기와 되감기, 문맥 사용량과 압축, 대화별 동작 설정을 추가했습니다.
- AI가 실제 작업 자료를 읽고 보고서와 인계를 작성해 별도 대화·산출물로 저장합니다. 주간업무보고의 프로젝트·기간·메모·모델 선택과 작성 이력, 업무 마감의 사유·최근 활동 프로젝트 선택을 제공합니다.
- 대화 간 요청·결과 회신 / 통합 결정함 / 알림 / 선택형 비서 감시·예약·AI 보고 / 팀 자동 계획·배정·재검수·통합 / AI 기억과 선택 가져오기·이동을 추가했습니다.
- 프로젝트 보드 / 카드 이전 / 여러 저장소·대화 작업 위치 / 목표 진척·이월·반복 / HTML 미리보기·수정·재변환·복원 / 편집 가능한 발표자료 / 저장 공간 분석과 안전한 정리를 추가했습니다.
- GitHub 계정별 실행과 저장소 단계 계획·실패 재개, 프로세스의 AI 종료 후보 분석과 선택 종료를 추가했습니다.
- Google 자료 본문·문서 형식·다중 캘린더와 검토 후 일정 변경, Mac 기본 메일·캘린더 연결을 추가했습니다. AI는 변경을 제안하며 사용자가 검토한 뒤 승인합니다.
- 모바일의 첨부·팀·결정·비서·설정·사용량과 종류별 웹 알림, 카카오 본인 채팅·허용 메일의 일회용 연결 주소를 추가했습니다.
- 선택형 로컬·연속 음성·호출어·답변 읽기, 곡에 맞춘 가사 검색과 시간별 표시를 추가했습니다.

## 설치와 업데이트

Mac ARM64 / Windows x64를 제공합니다. 각 설치 파일과 소스 묶음, 터미널 설치기, 보조 파일의 SHA-256은 `SHA256SUMS.txt`에 있습니다. 해당 소스 커밋은 `SOURCE-COMMIT.txt`에 기록합니다.

Windows는 새 버전 확인 → 다운로드 검증 → 설치 → 재시작을 지원합니다. Mac의 앱 내 교체는 새 앱의 Developer ID 서명과 Apple 공증을 확인해야 진행합니다. 이번 Mac 배포본은 임시 서명이며 공증되지 않았습니다. Windows 배포자 코드 서명도 없습니다. 다운로드본의 첫 실행에는 운영체제 확인이 나타날 수 있습니다.
