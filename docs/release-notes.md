# Flowrium 261114_02

대화를 열면 넓은 본문을 먼저 보여 주고 입력 영역과 안내를 간결하게 정리합니다. 긴 프로젝트 목록이 아래 메뉴와 겹치는 문제를 수정하고, 기능별 화면의 여백과 글자 높이, 버튼 역할을 설정 화면과 같은 기준으로 정리합니다.

## 변경

- 대화는 가용 폭을 사용하는 보기로 열립니다. **대시보드와 나란히 보기**와 **대화 크게 보기**로 전환할 수 있습니다.
- 상태와 연결 안내, 과거 기록 불러오기, 입력 도구를 간결하게 배치해 본문 공간을 확보합니다. 과거 기록 불러오기는 본문 위를 덮지 않고 함께 스크롤합니다. 전체 저장 기록과 내보내기는 유지합니다.
- 긴 프로젝트 목록을 보관 메뉴와 도구 메뉴에서 분리합니다. 화면 높이가 작아도 메뉴가 겹치지 않으며 아이콘과 글자는 왼쪽 시작점을 유지합니다.
- 대시보드와 프로젝트 상세, 목표와 산출물, 완료 기록과 보고를 얇은 테두리와 일정한 여백으로 정리합니다. 기억과 팀, 저장소와 서비스, 저장 공간도 같은 기준을 사용합니다.
- 외부 자료와 일정 검토, 휴대폰 알림과 음성 서버, 자료 이관과 음악, 터미널과 추가 입력 화면을 정돈합니다. 주요 실행은 강조하고 보조 행동은 투명한 버튼으로 묶습니다.
- 작은 화면은 한 열 배치와 자연스러운 문구 줄바꿈을 사용합니다. 용량 표와 코드처럼 가로 공간이 필요한 자료는 해당 영역에서만 스크롤합니다.
- 상태와 개수처럼 제목을 보충하는 정보는 괄호와 부제로 구분합니다. 설명은 짧은 문장으로 다듬고 경로와 URL, 원본 자료는 보존합니다.
- 파란색과 회색 팔레트, 나눔스퀘어라운드를 유지합니다. 팝업은 중앙에 표시하며 화면 움직임은 짧게 적용합니다. 기존 대화와 사용자 자료의 보관 방식도 유지합니다.

## 검증 준비 상태

새 버전의 최종 Mac과 Windows 기능 회귀는 아직 완료하지 않았습니다. 패키지와 설치, 업데이트, 공개 파일 대조도 확인해야 합니다. 이 노트는 소스 변경과 검증 계획을 설명하며 **261114_02 공개 완료를 뜻하지 않습니다.** 현재 공개 설치본과 이전 확정 결과는 [261114_01 릴리스](https://github.com/hyeondk/flowrium/releases/tag/261114_01)와 [검증 기록](https://github.com/hyeondk/flowrium/blob/main/docs/VALIDATION-261114_01.md)에서 확인합니다.

넓은 대화는 화면 크기별로 본문과 입력 높이, 가로 넘침, 과거 기록의 위치를 검사합니다. 긴 프로젝트 목록은 화면 높이별로 메뉴 접근을 확인하고, 기능별 화면은 여백과 작은 화면 배치를 검사합니다. 새 검사는 전체 배포 검증에 포함하며 하나라도 실패하면 설치 파일의 보관과 초안 릴리스 생성을 중단합니다. 재현용 이전 화면 옵션은 배포 검증에서 사용하지 않습니다.

개인 대화와 첨부, 원문과 인증 정보는 각 사용자의 기기에 저장하며 공개 소스와 설치본에는 포함하지 않습니다.

## 설치와 사용 조건

대상은 Mac ARM64와 Windows x64입니다. **0.6.0 이하에서 날짜 버전으로 전환하려면 한 번 수동 설치가 필요합니다.** 날짜 버전끼리는 날짜와 순번으로 업데이트를 확인합니다. Developer ID 서명과 Apple 공증이 없는 Mac은 수동 설치를 안내합니다. 터미널 설치도 보안 정책을 해제하거나 경고 없는 실행을 보장하지 않습니다.

같은 Codex 대화는 한 앱씩 번갈아 사용하며 작업 종료 뒤 다른 앱에서 새로고침합니다. 이미 열려 있는 원래 앱 화면의 즉시 갱신은 확인하지 않았습니다. 원래 앱 전용 도구에는 제약이 있으며, 연결 대화의 분기와 되감기, 압축이 필요하면 독립 사본을 선택합니다.
