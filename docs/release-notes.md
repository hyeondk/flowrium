## 맥에서 처음 설치하거나 업데이트할 때

- **처음 설치할 때** 디스크 이미지에서 Flowrium을 응용 프로그램 폴더로 옮긴 뒤 여세요. 임시 서명 배포본을 처음 열면 macOS가 개발자나 악성 소프트웨어를 확인할 수 없다는 창을 표시할 수 있습니다. 공식 릴리스 파일임을 확인했으면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 앱의 실행을 허용할 수 있습니다.
- **업데이트할 때** 임시 서명 배포본은 새 앱을 내려받아 기존 설치 위치에 교체해 주세요. 앱 내 자동 교체에는 Apple Developer ID 서명과 공증이 필요합니다. 수동 교체 뒤 새 앱을 열 때 실행 확인이 다시 표시될 수 있습니다. 설치 폴더에 관리자 권한이 필요한 경우에는 Finder가 복사나 교체를 승인하라는 창을 표시할 수 있습니다.
- **키체인 창이 뜰 때** `Flowrium Safe Storage`에 대한 macOS 접근 확인 창에 로그인 키체인 암호를 입력하세요. 기본값은 맥 사용자 로그인 암호입니다. 임시 서명은 버전마다 달라질 수 있어 **항상 허용**한 뒤에도 업데이트 후 다시 물을 수 있습니다.

- 목표 수치에는 더하기와 빼기 버튼, 목표일에는 달력, 반복 일정에는 시각 선택을 적용했습니다. 음량과 보기 전환도 같은 강조색과 키보드 조작을 따릅니다.
- 개인 비서는 Pro 계정에서 Dots를 열고, 그 밖의 요금제에서는 일반 비서 대화를 엽니다. 기존 대화 연결과 자료 이관은 **업무 연결 / 비서 → 자료 관리**에서 이용할 수 있습니다.
- 홈페이지에서 가상 온라인 스토어의 매출 자료와 대화를 보며 앱의 사용 방식을 확인할 수 있습니다.
