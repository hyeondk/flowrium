# Flowrium 261116_04

- 동기화된 대화에 있던 로컬 요청과 오류를 발생한 시각에 표시합니다. 이전 버전에서 저장한 대화를 다시 열어도 원본 대화의 순서와 첨부를 보존합니다.
- 원래 Codex 앱에서 같은 대화를 열어 둔 경우에도 짧은 글과 사진을 함께 보낼 수 있습니다. **추가 지시 → Codex 대화 설정으로 보내기**를 선택하면 원래 대화가 작업을 받습니다.
- 이전 요청의 실패와 최근 요청의 실패를 구분합니다. 실패 기록에 대응하는 요청이 있으면 **입력창에 다시 담기**로 본문과 첨부를 확인한 뒤 직접 전송할 수 있습니다.
- 긴 대화를 읽거나 사진이 포함된 큰 응답을 받을 때 연결이 끊어지는 문제를 개선했습니다. 목록이 한 번에 들어오지 않으면 나눠 읽습니다.
