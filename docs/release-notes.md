# Flowrium 261115_08

- 휴대폰에서 대시보드, 대화, 문서, 팀 등을 처음 불러올 때 스켈레톤을 표시합니다. 이미 열린 화면을 갱신할 때는 기존 내용과 읽던 위치를 유지합니다.
- 작업이나 팀 실행 중단, 대기 지시 및 예약 취소, 기기 알림 해제, 여러 결정의 일괄 처리에는 화면 아래에서 확인 창이 열립니다. 취소하면 원래 화면으로 돌아갑니다.
- 처리 결과는 하단 메뉴 위 같은 자리에서 나타났다가 사라집니다. 기기의 동작 줄이기 설정을 따릅니다.
