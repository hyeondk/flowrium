# Flowrium 261115_03

Flowrium의 개인 비서와 대화 후속 작업, 정리 기능을 개선했습니다.

- 공식 Dots 화면을 개인 비서에 통합했습니다. 각 사용자가 같은 ChatGPT 계정으로 처음 웹 로그인하고 이 기기에서 이어 씁니다.
- 질문과 실행 권한 요청은 즉시 알림과 중앙 응답 카드에서 처리합니다. 알림은 헤더 클릭을 가리지 않습니다.
- 대기 중인 대화에 진행하기를 추가하고 다음 작업 추천을 기존 초안에 넣어 수정할 수 있게 했습니다.
- 휴지통의 선택 영구 삭제와 비우기를 추가했습니다. 원본 프로젝트와 공유 자료는 보존합니다.
- 채팅 폭 드래그와 키보드 조절, 모델 원문 표시, 중앙 팝업 닫힘 애니메이션을 적용했습니다.
- 모델 전환 시 서버가 지원하는 추론 강도로 맞추고, 지원 정보가 없으면 강도를 지정하지 않습니다.
- 맥의 정상 종료 후 프로세스가 남던 문제와 닫힌 창의 재실행을 보완했습니다.
- 작은 창의 입력 영역을 줄이고 왼쪽 도구 아래에 여백을 두었습니다. 제작자 표시는 메뉴를 펼쳤을 때 보입니다.
- 구글 연결 기능을 제거했습니다. 프로젝트와 대화는 사용자가 고른 로컬 위치에 보관합니다.

Mac Apple Silicon과 Windows 64비트를 제공합니다. 공개 Mac 파일은 Apple 공증이 없으며 첫 실행이나 교체 뒤 운영체제가 파일 접근 권한을 요청할 수 있습니다. 설치 파일과 개인 프로젝트·계정 자료는 분리되어 있습니다.

같은 Codex 대화는 한 앱에서 작업을 마친 뒤 다른 앱에서 새로고침해 이어 씁니다. 연결 대화의 분기와 되감기 및 압축에는 제한이 있으며, ChatGPT 웹 전체 대화의 자동 양방향 동기화는 제공하지 않습니다.
