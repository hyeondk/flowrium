# Flowrium 261116_03

- 연결한 대화에서 양쪽 앱의 사용자 요청과 응답을 자동으로 확인합니다. 대시보드를 보고 있어도 최근 변경과 작업 중인 대화를 우선 확인합니다.
- 등록한 프로젝트의 새 Codex 대화를 찾고 같은 원본에 연결합니다. 공식 프로젝트와 연결된 경우 프로젝트 이름과 대화 제목 변경을 주고받습니다.
- 연결 대화의 보관과 복원을 반영하고, 원본까지 지울 때 삭제 범위를 확인합니다. 프로젝트 등록을 제거해도 작업 폴더의 파일은 보존합니다.

- 긴 대화의 과거 개정은 연결 정보만 메모리에 유지합니다. 작업 중에 보이는 중간 응답은 임시로 표시하고 최종 기록을 저장합니다.

## 대화 입력과 기록

- 긴 기존 대화를 이어 쓸 때 필요한 연결 정보만 요청합니다. 이전 메시지와 사진은 원본에 보관하고, 화면에서 필요한 기록을 나눠 읽습니다.
- ChatGPT가 같은 로컬 대화의 작성 권한을 사용하고 있는지 확인하고, 사용자가 보낸 요청의 대기 상태를 표시합니다.
- 채팅 입력창에서 작성 중인 마크다운을 바로 확인할 수 있습니다. 보낼 때에는 작성한 원문을 사용합니다.
- 긴 글도 같은 입력창에 붙여넣어 보낼 수 있습니다. 32,000자를 넘는 요청은 원문을 보관해 나누어 읽습니다. 200만자를 넘는 요청은 UTF-8 기준 20MiB까지 자동으로 텍스트 첨부로 보관합니다.
- 가져온 메시지에서 첨부 사진의 자동 파일명과 임시 경로가 본문에 반복되는 문제를 수정했습니다. 작업 과정 원문은 대화 폭에 맞춰 줄을 바꿔 표시합니다.
