Flowrium 0.5.0은 가운데 작업 화면을 유지하는 오른쪽 대화함과 자동으로 펼쳐지는 왼쪽 메뉴를 제공합니다.

- 통합 채팅 / 프로젝트 대화 / 일반 대화를 따로 운영합니다. 통합 채팅의 업무 제안은 결정함 승인 뒤 프로젝트에서 실행하고 결과를 회신합니다.
- 작업중 / 대기 / 결정을 실제 실행과 요청으로 구분하고 상태별 대화를 찾습니다.
- 공식 나눔스퀘어라운드 / 일정한 행 높이 / 회색과 보라색 강조 / 팝업과 알림 입퇴장 / 하단 시트 / 체크 선 / 제목 순차 등장 / 동작 줄이기를 적용했습니다.
- 일반 대화의 파일·명령 접근 제한, 계정별 대화와 첨부 분리, 내보내기 중 잠금 변경 차단을 보강했습니다.
- 기존 첨부 / 추가 지시 / 분기·되감기 / 초안 / 업무 보고 / 팀 / 목표 / 산출물 기능을 유지합니다.

Apple Silicon Mac / Windows 64비트 설치 파일을 제공합니다. 각 사용자는 본인의 ChatGPT 계정으로 로그인합니다. 실제 계정의 일반 대화와 통합 현황 도구를 합성 자료로 검사했습니다.

Mac 다운로드본은 Apple 공증이 없어 최초 실행 제한이 생길 수 있습니다. 미공증 버전의 앱 내부 자동 교체는 차단하고 수동·터미널 설치를 안내합니다. 터미널 설치도 운영체제 보안을 해제하지 않습니다. Windows는 다운로드·설치·재시작 경로를 지원합니다.
