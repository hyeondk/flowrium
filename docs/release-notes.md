# Flowrium 261119_12

- 프로젝트의 하위 메뉴에서 상단의 **← 프로젝트** 버튼을 눌러 해당 프로젝트 홈으로 돌아갈 수 있습니다. 화살표와 글자를 같은 줄의 중앙에 맞췄습니다.

## 261119_11

- 추천을 열기 전에는 다음 작업 추천과 진행하기 / 완료가 한 줄에 표시됩니다. 추천이 나타나면 문구가 전체 너비를 사용합니다.
- 계정과 모델에서 기본 실행 속도를 고를 수 있습니다. 대화마다 모델 옆 추론 슬라이더와 번개 버튼에서 값을 저장할 수 있고, 모델과 계정이 지원하는 속도가 표시됩니다.
- Codex가 원래 대화를 사용 중일 때 **지금 분기해 실행**을 선택하면 마지막 완료 지점부터 별도 대화에서 요청을 실행합니다.
- Codex에서 실행 중인 대화의 상태와 확인된 진행 설명, 파일·도구 작업을 Flowrium에 표시합니다.
- 대화 상단 설정 옆의 짧은 막대에 컨텍스트 사용량을 표시합니다. 마우스를 올리거나 키보드로 초점을 주면 사용률과 토큰 한도를 확인할 수 있습니다.
- 답변의 Codex 이름과 아이콘을 한 줄의 가운데에 맞췄습니다.

## 261119_06

- 대화 입력창에서 이전 요청과 답변에 맞는 다음 작업을 추천합니다. 제안을 선택하면 초안에 넣고 직접 수정한 뒤 보낼 수 있습니다.
- 모델이 응답 중이면 작업중, 다음 작업이 남아 있으면 대기, 어시스턴트의 질문에 응답해야 하면 결정으로 표시합니다. 대기에는 진행과 완료 버튼이 표시됩니다.
- 답변 완료나 결정 요청이 도착하면 대상 대화와 알림 이유를 표시합니다. 잠금 중 알림 미리보기는 개인 정보를 보호합니다.
- 종 아이콘의 알림 숫자는 작고 둥근 배지로 표시합니다.
- 휴대폰에서 긴 요청을 보낼 때 각 조각의 임시 저장이 끝난 뒤에 다음 조각으로 넘어갑니다.
- 홈 대시보드와 좌우 패널에서 프로젝트를 길게 눌러 순서를 바꿀 수 있습니다. 끌 때 카드가 들리고 주변 카드가 새 위치로 이동합니다. 놓은 순서는 세 화면에 함께 저장됩니다.
- 왼쪽 패널의 대시보드·프로젝트 제목과 프로젝트 행의 높이, 간격, 아이콘과 글자 기준선을 맞췄습니다.

## 261118_07

- 프로젝트를 고를 때 분류 아이콘과 이름을 프로젝트명 앞에 표시했어요.
- 왼쪽 메뉴의 기능명을 굵게 표시하고 프로젝트 제목과 대시보드의 글자 크기를 맞췄어요. 모든 프로젝트 행의 높이와 간격을 맞추고, 해당 폴더 아이콘의 윗 테두리에 작업중 / 대기 / 결정 상태 배너를 겹쳐 표시했어요. 강조색에 맞춰 배경도 바뀌게 했어요.
- 설정 창의 높이를 일정하게 유지하고 일반 탭에 최신 업데이트 기록을 추가했어요.
- 선택 목록을 화면 위에 띄우고 열 수 있는 공간에 맞춰 아래나 위로 펼치게 했어요. 항목 선택 뒤에는 원래 입력으로 초점이 돌아오게 했어요.
- 내 메시지는 오른쪽, Codex 답변은 왼쪽의 둥근 말풍선으로 표시했어요. 시각과 복사 버튼을 말풍선 밖에 배치하고 Codex 아이콘과 이름은 한 줄에 정렬했어요.
- 대화 종류와 제목 사이에 여백을 두고, 문맥 토큰 사용량을 설정 아이콘 옆에 표시했어요. 자동 동기화 버튼을 정렬했고 음성 연결 안내는 5초 뒤에 닫히게 했어요.
- 좁은 창에서 프로젝트 도구 버튼이 겹치지 않도록 줄을 나눠 배치했어요.
- 프로젝트와 대화 찾기의 단축키 표기를 조금 키웠어요.

## 맥에서 처음 설치하거나 업데이트할 때

- **처음 설치할 때** 디스크 이미지에서 Flowrium을 응용 프로그램 폴더로 옮긴 뒤 여세요. 임시 서명 배포본을 처음 열면 macOS가 개발자나 악성 소프트웨어를 확인할 수 없다는 창을 표시할 수 있습니다. 공식 릴리스 파일임을 확인했으면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 앱의 실행을 허용할 수 있습니다.
- **업데이트할 때** 임시 서명 배포본은 새 앱을 내려받아 기존 설치 위치에 교체해 주세요. 앱 내 자동 교체에는 Apple Developer ID 서명과 공증이 필요합니다. 수동 교체 뒤 새 앱을 열 때 실행 확인이 다시 표시될 수 있습니다. 설치 폴더에 관리자 권한이 필요한 경우에는 Finder가 복사나 교체를 승인하라는 창을 표시할 수 있습니다.
- **키체인 창이 뜰 때** `Flowrium Safe Storage`에 대한 macOS 접근 확인 창에 로그인 키체인 암호를 입력하세요. 기본값은 맥 사용자 로그인 암호입니다. 임시 서명은 버전마다 달라질 수 있어 **항상 허용**한 뒤에도 업데이트 후 다시 물을 수 있습니다.

[맥 설치와 업데이트 안내](https://github.com/hyeondk/flowrium/blob/main/README.md#local-mac) / [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445) / [Apple의 키체인 안내](https://support.apple.com/ko-kr/guide/mac-help/kychn002/mac)

## 261118_02

- 대시보드에서 프로젝트는 한 줄에 세 개, 최근 업무는 두 개씩 표시합니다. 창을 좁히면 열 수가 줄어듭니다. 프로젝트를 우클릭하거나 설정에서 카테고리를 바꿀 수 있습니다.
- 대화창을 접으면 오른쪽 가장자리에 다시 여는 탭이 남습니다. 대화 종류 아래의 뒤로 가기를 이용하면 선택한 프로젝트의 대화 목록으로 돌아갑니다.
- 왼쪽 메뉴를 펼쳐도 아이콘 위치가 유지됩니다. 사용량과 그래프는 한 줄에 표시하고, 크레딧은 메뉴를 펼치면 확인할 수 있습니다.
- 프로젝트 상세와 업무 설정의 여백을 줄였습니다. 프로젝트 메뉴의 규칙 / 디자인 시안 / 회의록은 문서에서 찾을 수 있습니다. 앱을 시작하거나 프로젝트를 불러오는 동안에는 진행 막대가 표시됩니다.

## 261118_01

- 확정 시안에 맞춰 데스크톱의 탐색 영역 / 프로젝트 본문 / 대화 패널을 다시 구성했습니다. 목표 / 할 일 / 최근 활동은 문서형 화면으로 표시하고, 분석 지표와 상세 메뉴는 필요한 때 펼칩니다. 대시보드의 프로젝트도 같은 행 목록으로 정리했습니다.
- 데스크톱 전체의 기본 배율을 **87%**로 설정했습니다. 메뉴와 입력창을 포함해 함께 줄어들며, 대화 본문에 축소를 중복 적용하지 않습니다. 보기 메뉴의 기본 크기 또는 Command+0 / Ctrl+0으로 87%로 돌아갑니다. 휴대폰 화면의 배율은 유지합니다.
- 대화 제목 옆 조작을 메뉴로 모으고 답변 동작은 본문 아래에 배치했습니다. 긴 대화는 패널 안에서 독립적으로 스크롤하며 입력창은 하단을 유지합니다. 기존 대화 / 설정 / 프로젝트 권한 / 휴대폰 연결 저장 정보는 유지합니다.
- 좌측 사용량에서 시간 구간 이름을 제거했습니다. 로그인한 계정이 제공한 현재 한도와 남은 양을 표시하고, 새로고침과 계정 전환에 맞춰 갱신합니다. 한도가 제공되지 않으면 임의의 잔량을 표시하지 않습니다.

## 261117_01

- 프로젝트 첫 요청에서 폴더 경로를 확인하고 **신뢰하고 편집 허용**을 누르세요. 이후 기존·새 대화 모두에서 프로젝트 파일을 바로 읽고 수정할 수 있습니다. 앱을 다시 열거나 업데이트해도 같은 계정과 폴더의 선택을 기억합니다.
- 20MiB를 넘는 채팅 원문도 입력창에서 한 번에 보낼 수 있습니다. 긴 원문을 보관한 뒤 필요한 부분을 읽으며, 휴대폰에서는 자동으로 나눠 전송합니다.
- PC에서 왼쪽 메뉴를 한 곳으로 모았습니다. 오른쪽 대화창은 원하는 폭으로 조절할 수 있습니다. 팝업이 닫히는 마지막 순간까지 내용과 배경이 함께 사라집니다.
- 답변에 다음 작업이 있으면 기기 안에서 추천 한 건을 만듭니다. 문구를 누르거나 Tab을 눌러 초안에 넣으세요. 작업 내역은 한 줄로 접을 수 있고, 기록된 시각이 있으면 소요 시간을 표시합니다.
- 휴대폰 하단 탭의 선택 표시가 손가락을 따라 움직입니다. 컴퓨터와 휴대폰에서 같은 밝기와 강조색을 사용합니다. 기존 휴대폰 연결 방식에서 넘어오는 경우 새 QR 코드를 한 번 스캔하세요. 이후 같은 기기에서 앱을 교체해도 중계 주소가 유지되면 다시 연결됩니다.
- 목표 수치에는 더하기와 빼기 버튼, 목표일에는 달력, 반복 일정에는 시각 선택을 적용했습니다. 음량과 보기 전환도 같은 강조색과 키보드 조작을 따릅니다.
- 개인 비서는 Pro 계정에서 Dots를 열고, 그 밖의 요금제에서는 일반 비서 대화를 엽니다. 기존 대화 연결과 자료 이관은 **업무 연결 / 비서 → 자료 관리**에서 이용할 수 있습니다.
- 홈페이지에서 가상 온라인 스토어의 매출 자료와 대화를 보며 앱의 사용 방식을 확인할 수 있습니다.
