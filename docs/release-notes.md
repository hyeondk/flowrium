# Flowrium 261115_02

오른쪽에서 AI 대화를 이어가면서 왼쪽의 대시보드와 프로젝트를 독립적으로 탐색합니다. 조밀한 파란색·회색 화면과 중앙 팝업을 적용하고, 대화 본문과 접어서 보는 작업 기록을 구분합니다.

## 변경

- 대화함에 **통합, 프로젝트, 일반, Dots** 탭을 제공합니다. 대화 선택과 왼쪽 프로젝트 탐색을 분리하며 미전송 초안을 유지합니다. 패널의 고정·겹쳐 보기·입력창만 보기를 선택하고 폭을 조절할 수 있습니다.
- 작성 서식의 내부 표시는 숨기고 본문을 읽기 좋게 표시합니다. 도구·시스템 기록은 기본으로 접고, 원문 확인과 복사는 명시적으로 제공합니다. 원본 데이터는 잘라 저장하지 않습니다.
- 본문의 표와 체크 목록, 취소선, 각주를 표시합니다. 넓은 표는 표 안에서만 스크롤하며 작은 화면의 본문 폭을 유지합니다.
- 프로젝트 목록에 공간을 더 배정하고 하단 도구와 버튼을 줄였습니다. 파란 Flow 아이콘을 중앙에 배치하고 도움말, 제작자 표시, 계정의 남은 사용량을 제공합니다.
- 음악과 알림을 중앙 팝업으로 표시합니다. 조사, 통합 브리핑, 문서 작성도 프로젝트와 실제 사용 가능한 모델을 고르는 팝업에서 시작합니다.
- 오른쪽 클릭으로 프로젝트와 대화를 휴지통에 보관하고 복원합니다. 원래 Codex 대화의 보관·영구 삭제는 별도 선택과 확인을 거칩니다. ChatGPT 웹 대화의 삭제를 함께 수행하지는 않습니다.
- 월별·목록형 Google 일정, 일정 변경 검토, 오늘 일정과 읽지 않은 메일 요약을 제공합니다. 공개 Google 로그인에 필요한 OAuth 등록은 아직 준비되지 않았습니다.
- Dots는 공식 웹 화면을 분리된 로그인 영역에 표시합니다. 계정별 이용 조건은 공식 서비스에 따르며, 자동 대화 동기화와 통화는 제공하지 않습니다.
- 프로젝트 바로가기, 외부 등록 프로젝트의 저장소 연결, 저장소 병합 후 업무 완료 흐름을 추가했습니다. 권한은 이 기기에 보관하며 옮긴 폴더에서는 다시 확인합니다.
- Mac의 한글 경로를 서로 다른 방식으로 반환하는 실행 환경에서 같은 폴더를 다른 위치로 판단하던 오류를 수정했습니다.

## 검증 결과

Mac 단위 검사 300개와 순차 회귀 40종, 최종 빌드 후 재검증 13종을 통과했습니다. Windows의 전체 기능·실설치·업데이트 검사와 Mac 설치본 검증은 진행 중입니다. 실제 완료 범위는 [261115_02 검증 기록](VALIDATION-261115_02.md)에 기록합니다.

개인 대화와 첨부, 원문과 인증 정보는 각 사용자의 기기에 저장하며 공개 소스와 설치본에는 포함하지 않습니다.

## 설치와 사용 조건

대상은 Mac ARM64와 Windows x64입니다. **0.6.0 이하에서 날짜 버전으로 전환하려면 한 번 수동 설치가 필요합니다.** 날짜 버전끼리는 날짜와 순번으로 업데이트를 확인합니다. Developer ID 서명과 Apple 공증이 없는 Mac은 수동 설치를 안내합니다. 터미널 설치도 보안 정책을 해제하거나 경고 없는 실행을 보장하지 않습니다.

같은 Codex 대화는 한 앱씩 번갈아 사용하며 작업 종료 뒤 다른 앱에서 새로고침합니다. 이미 열려 있는 원래 앱 화면의 즉시 갱신은 확인하지 않았습니다. 원래 앱 전용 도구에는 제약이 있으며, 연결 대화의 분기와 되감기, 압축이 필요하면 독립 사본을 선택합니다.
