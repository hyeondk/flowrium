# Flowrium 261115_06

- **대화별 모델**을 채팅 입력창에서 선택할 수 있습니다. **기본 설정 따르기**로 되돌리면 설정에 지정한 모델을 사용합니다. 휴대폰에서도 각 대화의 선택이 이어집니다.
- **대기**에 **완료**가 추가됐습니다. 후속 실행 없이 이번 대기를 해제하고 대화와 초안을 보존합니다. 다음 작업 추천은 초안에 넣고 수정한 뒤 전송할 수 있습니다.
- 우측 채팅 패널의 기본 폭을 줄이고 입력창에 높이 조절 손잡이를 추가했습니다. 내 메시지는 사람 아이콘, 답변은 ChatGPT 아이콘으로 구분합니다. 팝업은 가로세로 비율을 유지하며 중앙으로 축소되고 서서히 사라집니다. [채팅 화면](https://github.com/hyeondk/flowrium/blob/261115_06/docs/chat-261115_06.png)
- **휴대폰 대시보드**에서 오늘 할 일, 최근 7일 흐름, 프로젝트 현황을 보고 **작업중 / 대기 / 결정**에서 해당 대화로 이동할 수 있습니다. 대화 상태는 화면을 보는 동안 2초마다, 다른 앱에서 돌아오면 즉시 확인합니다. [휴대폰 대시보드](https://github.com/hyeondk/flowrium/blob/261115_06/docs/mobile-dashboard-261115_06.png)
- 휴대폰 카메라로 컴퓨터에 표시된 QR 코드를 스캔하세요. 휴대폰의 하단 **설정**에 **도움말**과 **홈 화면에 설치**가 있습니다. 사용량이 갱신되어도 편집 중인 설정값은 유지됩니다. 데스크톱의 임시 주소가 바뀌면 새 주소로 홈 화면에 추가하세요. [휴대폰 설정](https://github.com/hyeondk/flowrium/blob/261115_06/docs/mobile-settings-261115_06.png)

Apple Silicon 맥과 64비트 윈도우용입니다. 맥 공개본은 Apple 미공증 상태로 수동 설치할 수 있습니다. [다운로드](https://hyeondk.github.io/flowrium/) / [터미널 설치](https://github.com/hyeondk/flowrium/blob/261115_06/docs/TERMINAL-INSTALL.md) / [기능 검증 기록](https://github.com/hyeondk/flowrium/blob/main/docs/VALIDATION-261115_06.md)
